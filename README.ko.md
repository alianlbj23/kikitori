# kikitori（聞き取り）

[繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [English](README.md) | [日本語](README.ja.md) | **한국어** | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md) | [Tiếng Việt](README.vi.md) | [ไทย](README.th.md) | [Bahasa Indonesia](README.id.md)

*이 문서는 번체 중국어 [README.zh-TW.md](README.zh-TW.md)의 번역본입니다. 내용이 다를 경우 README.zh-TW.md가 우선합니다. 이 문서는 AI의 도움을 받아 번역했으며, 잘못된 부분은 [issues](https://github.com/alianlbj23/kikitori/issues)로 알려 주시면 감사하겠습니다.*

kikitori는 컴퓨터에서 재생 중인 소리(또는 마이크)를 듣고 실시간으로 텍스트로 인식한 뒤, 선택한 언어로 번역해 화면 위에 떠 있는 이중 언어 자막으로 보여 줍니다.
음성 인식(Whisper)과 번역(로컬 Ollama)은 모두 사용자의 컴퓨터에서 실행됩니다. 소리와 텍스트는 어떤 클라우드 서비스에도 업로드되지 않습니다.

주요 사용 사례는 **일본어 VTuber 방송 시청**(BGM, 게임 효과음, 방송 용어가 섞인 환경)이며, 모델 추천과 매개변수는 이 프로젝트의 실측 결과에 맞춰 조정했습니다.
20개 언어 간의 다른 조합도 사용할 수 있습니다.

- 플랫폼: Windows 10/11 x64(주요 검증 플랫폼), Linux x64, macOS Apple Silicon
- 라이선스: MIT(각 모델은 별도 라이선스, '라이선스' 참고)
- 현재 버전: 0.3.1([변경 내용](docs/release-notes/v0.3.1.md))

## 기능

| 기능 | 설명 |
|---|---|
| 영상 번역 | 시스템에서 재생되는 소리를 캡처해(Windows WASAPI loopback／Linux PulseAudio monitor／macOS ScreenCaptureKit) 듣는 언어를 자막 언어로 번역 |
| 실시간 통역 | 마이크를 캡처. 내가 '내 언어'로 말하면 상대방 언어로, 상대방이 말하면 내 언어로 번역 |
| 빠른 자막 뒤 정확한 자막, 이중 경로 | 말하는 도중에는 빠른 모델로 '실시간 자막'을 먼저 보여 주고, 말이 끝나면 더 정확한 모델로 다시 계산한 '최종 자막'으로 교체 |
| 안정적인 실시간 자막 | 실시간 자막의 원문과 번역문 중 더 이상 바뀌지 않는 앞부분은 일반 표시, 아직 바뀌는 끝부분은 흐린 색으로 표시. 새로 나온 글자는 페이드인되고 자막 전체가 위아래로 튀지 않음 |
| 화자 라벨 | 여러 명이 합방할 때 문장마다 앞에 '화자 1, 2…'를 표시. 인원은 자동 판별하거나 2–6명으로 지정할 수 있고, 라벨을 클릭해 이름 변경 가능. 통역 모드에서는 '나／상대'를 표시 |
| 20개 언어 임의 조합 | 듣는 언어('자동 감지' 선택 가능)와 자막 언어를 20개 언어 중에서 자유롭게 선택. '지원 언어' 참고 |
| 13개 인터페이스 언어 | 기본값은 운영체제 언어를 따르며 설정 페이지에서 변경 가능 |
| 원문만 표시 | '번역 표시'를 끄면 원문만 표시. Ollama가 필요 없고 GPU도 쓰지 않음. 실행 중에도 전환 가능 |
| 후리가나 | 일본어 원문의 한자 위에 읽는 법을 표시(SudachiDict, 처음 켤 때 약 69 MiB 다운로드) |
| 하드웨어별 모델 추천 | CPU, 메모리, NVIDIA 그래픽 카드, Ollama를 감지해 모델 구성을 자동 선택. 부족한 모델은 처음 '시작'을 누를 때 다운로드 |
| 용어집 | 일본어 방송 용어 53개(赤スパ, 推し, メン限…)와 중→일 번역에서 헷갈리기 쉬운 중일 단어 내장. 항목 직접 추가, CSV 가져오기／내보내기 가능 |
| 인식 결과 수정과 이번 방송 정보 | 인식이 자주 틀리는 글자를 자동으로 바로잡음. 방송인 이름, 게임 이름, 방송 설명란을 입력하면 이름이 일관되게 번역됨 |
| 자막 기록 내보내기 | SRT, VTT, TXT, CSV. 끝날 때마다 자동 저장하도록 설정 가능 |
| OBS 텍스트 파일 | 현재 자막을 텍스트 파일에 기록해 OBS '텍스트 (GDI+)' 소스의 '파일에서 불러들이기'에서 사용. 네트워크 포트를 열지 않음 |
| 자막 창 | 투명, 항상 위, 클릭 통과 지원. 글자 크기, 배경, 위치, 문장 수, 문장별 최소 표시 시간, 유휴 후 페이드아웃까지의 시간, 원문 크기와 위치, 줄 너비 조정 가능. 일시 정지와 최근 자막 다시 보기 가능 |
| 상태 표시줄 | 음량 표시, 지연 시간(말이 끝난 뒤 최종 자막까지의 중앙값). 인식이 따라가지 못하거나, 15초 동안 소리가 없거나, 배경음이 너무 크면 알림 |
| 모델 관리 | 음성 인식 모델 다운로드, 디스크 사용량 확인, 삭제. Ollama에 번역 모델 다운로드 대행 |
| 자동 업데이트 | 시작할 때 GitHub Releases를 확인하고, 다운로드 후 서명을 검증한 다음 설치 |

## 지원 언어

듣는 언어와 자막 언어(20개, 임의 조합):

| | | | | |
|---|---|---|---|---|
| 日本語 | English | 繁體中文（台灣） | 简体中文 | 한국어 |
| Español | Français | Deutsch | Português | Русский |
| Italiano | العربية | हिन्दी | Bahasa Indonesia | Tiếng Việt |
| ไทย | Türkçe | Polski | Nederlands | Українська |

- 번체 중국어 자막은 OpenCC `s2twp`로 대만 정체자와 대만식 표현으로 변환합니다(예: 视频 → 影片). 번역문에 간체자가 있을 때만 변환하며, '台灣'을 '臺灣'으로 바꾸지는 않습니다.
- 듣는 언어와 자막 언어가 같으면 번역하지 않습니다(번체와 간체 사이에는 글자 형태만 변환).
- 음성 인식 품질은 언어에 따라 다릅니다. 모델의 특정 언어 오류율이 20%를 넘으면(예: large-v3-turbo의 태국어, 아랍어, 힌디어, large-v3의 베트남어) 추천 설명에 '인식 품질이 낮습니다'라는 안내가 표시됩니다. 태국어, 아랍어, 힌디어는 8 GB 이상의 그래픽 카드에서 실시간 자막에도 large-v3를 사용합니다.

인터페이스 언어(13개): 繁體中文（台灣）, 简体中文, English, 日本語, 한국어, Español, Français, Deutsch, Português (Brasil), Русский, Tiếng Việt, ไทย, Bahasa Indonesia.
아랍어는 듣는 언어나 자막 언어로 쓸 수 있지만, 아랍어 인터페이스는 없습니다(인터페이스가 오른쪽에서 왼쪽으로 쓰는 레이아웃을 지원하지 않음).

## 추천 구성(하드웨어별)

kikitori가 자동으로 감지해 적용합니다. 아래 표는 어떤 구성이 선택되는지 알려 주기 위한 것입니다. 근거는 이 프로젝트의 평가(`experiments/vtuber_eval/`, `experiments/translate_eval/`)이며, 규칙과 계산식은 [`docs/specs/hardware.md`](docs/specs/hardware.md)를 참고하세요.

| 사용자의 컴퓨터 | 실시간 자막 | 최종 자막 | 번역(Ollama) |
|---|---|---|---|
| NVIDIA 16 GB 이상 | large-v3-turbo(float16) | large-v3(float16) | qwen3.5:9b |
| NVIDIA 12 GB(예: RTX 5070) | large-v3-turbo(int8_float16) | large-v3(int8_float16) | qwen3.5:9b |
| NVIDIA 8–11 GB | large-v3-turbo(VRAM이 하한선인 8 GB에 딱 맞으면 small) | large-v3(VRAM에 따라 정밀도 선택) | qwen3.5:4b |
| NVIDIA 4–8 GB | base | large-v3-turbo | qwen3.5:4b |
| NVIDIA 4 GB 미만 | base | small | qwen3.5:4b |
| NVIDIA GPU 없음, RAM ≥ 16 GB, 5코어 이상 | base(CPU) | small(CPU) | qwen3.5:4b |
| NVIDIA GPU 없음, RAM이 적거나 4코어 이하 | tiny(CPU) | base(CPU) | qwen3.5:4b |
| Mac(Apple Silicon) | base(CPU) | small(CPU) | 통합 메모리 용량에 따라(16 GB는 qwen3.5:9b) |

- 정밀도 int8_float16과 float16의 인식 품질은 실측상 같고(차이가 유의하지 않음), VRAM만 약 절반으로 줄어듭니다. 번역 모델과 그래픽 카드를 함께 쓸 때 kikitori는 번역 모델을 한 단계 큰 것으로 쓰는 것을 우선합니다.
- 음성 인식 모델 다운로드 크기: large-v3-turbo 1.62 GB, large-v3 3.09 GB, small 487 MB, base 148 MB, tiny 78 MB. 번역 모델: qwen3.5:9b 약 6.6 GB, qwen3.5:4b 약 3.3 GB.
- NVIDIA GPU에는 cuBLAS 12(약 570 MB)가 필요합니다. kikitori 설치 파일에는 포함되어 있지 않으며, '모델' 페이지에서 NVIDIA EULA에 동의하면 클릭 한 번으로 다운로드합니다. 설치되지 않은 경우 CPU를 사용합니다.
- 번역 서버가 다른 컴퓨터(원격)에 있으면 번역 모델을 자동으로 선택하지 않으니 '모델' 페이지에서 직접 선택하세요.
- 번역에는 항상 Qwen3.5(Apache-2.0)를 우선 추천합니다. VRAM이 충분하면 9B, 아니면 4B입니다. 그래픽 카드가 4 GB 이하이거나 NVIDIA GPU가 없을 때도 qwen3.5:4b를 쓰며, 들어가지 않는 부분은 Ollama가 CPU에서 실행하므로 느려집니다(이 경우의 번역 지연 시간은 아직 실측하지 않았습니다).
- Tencent HY-MT는 지역 제한이 있어, 설정 페이지에서 'EU, 영국 또는 한국에서 kikitori를 사용하지 않음을 확인하며…'를 체크한 경우에만 추천될 수 있습니다. Sakura(비상업 라이선스)는 절대 추천되지 않으며 직접 선택해야만 쓸 수 있습니다.
- macOS와 Linux의 인식 속도, CPU에서의 번역 속도는 아직 실측하지 않았습니다('알려진 제한 사항' 참고).

## 시작하기

1. [GitHub Releases](https://github.com/alianlbj23/kikitori/releases)에서 설치 파일을 다운로드합니다(플랫폼별 설치 안내는 Release 페이지에 있습니다: 서명되지 않은 앱에 대한 SmartScreen／Gatekeeper 경고, Linux의 fuse3와 글꼴).
2. 번역을 사용하려면 [Ollama](https://ollama.com/download)를 설치하고 백그라운드에서 실행해 둡니다. kikitori가 Ollama를 감지하지 못하면 'Ollama 설치' 또는 '원문만 표시'를 안내합니다.
3. kikitori를 엽니다. 처음 실행하면 하드웨어에 맞는 추천 구성이 자동으로 적용됩니다.
4. 설정 페이지의 '언어'에서 듣는 언어와 자막 언어를 선택합니다. 선택하면 추천 구성과 다운로드 크기만 표시되며, **바로 다운로드하지 않습니다**.
5. 오디오 소스를 선택하고 '시작'을 누릅니다. 부족한 음성 인식 모델과 번역 모델(Ollama 사용 시)을 먼저 다운로드하고, 완료되면 자동으로 시작합니다.

### 원문만 표시

자막 기록 페이지 도구 모음과 설정 페이지 '자막' 영역에 있는 '번역 표시' 스위치(또는 단축키 Ctrl+Alt+J)로 전환합니다. 끄면:

- 엔진이 번역 서버에 전혀 연결하지 않으므로 Ollama를 설치할 필요가 없고, 번역 모델용으로 GPU를 쓰지도 않습니다.
- 자막 창에서 원문이 주 자막의 글자 크기와 색으로 표시됩니다.
- 실행 중에 전환하면 바로 적용되며, 이미 표시된 문장을 나중에 번역하지는 않습니다.

### 후리가나

설정 페이지의 '일본어 원문에 후리가나 표시': 듣는 언어가 일본어일 때 원문의 한자 위에 히라가나로 읽는 법을 표시합니다(오쿠리가나(送り仮名)에는 중복으로 달지 않음). 처음 켤 때 SudachiDict core(Apache-2.0, 약 69 MiB)를 다운로드하며, '모델' 페이지에서 사용량을 확인하고 삭제할 수 있습니다. 화면 표시만 바뀌고 내보내는 자막은 그대로입니다. 설계는 [`docs/specs/furigana.md`](docs/specs/furigana.md)를 참고하세요.

### 용어집

설정 페이지의 '용어집':

- **내장 방송 용어집**(기본값 켜짐): 원문이 일본어이고 자막이 번체 중국어／간체 중국어／영어／한국어일 때 사용합니다. 예: スパチャ → 슈퍼챗, メン限 → 멤버십 전용, 切り抜き → 클립. 해당 문장의 원문에 실제로 나온 단어만 번역 프롬프트에 넣습니다(문장당 최대 8개).
- **헷갈리기 쉬운 중일 단어**(내장 용어집 스위치를 따름): 원문이 중국어이고 자막이 일본어일 때, 중국어와 일본어의 표기가 같거나 비슷하지만 뜻이 다른 단어를 알려 줍니다. 예: 便當 → 弁当, 節目 → 番組, 老婆 → 妻. 중→일 번역에서는 모델에 주는 지시문도 중국어로 써서, 모델이 중국어를 일본어 뜻으로 읽는 일을 줄입니다.
- **직접 추가한 항목**: 원문, 번역, 적용할 자막 언어(또는 '모든 언어'). 최대 500개이며 듣는 언어와 관계없이 적용됩니다. 표기가 같으면 내장 용어집보다 우선합니다. 대소문자와 전각／반각을 구분하지 않고 비교합니다.
- CSV 가져오기／내보내기를 지원합니다(UTF-8, 쉼표·세미콜론·탭 구분, Excel에서 저장한 파일도 읽을 수 있음). '용어집 저장'을 누르면 다음에 자막을 시작할 때부터 적용됩니다.

### 자막 기록 내보내기

자막 기록 페이지의 '내보내기': SRT, VTT, TXT, CSV 형식이며 내용은 '원문과 번역', '원문만', '번역만' 중에서 선택합니다. 최종 자막만 내보냅니다(실시간 자막은 아직 바뀌는 중이므로).
파일은 `문서/kikitori/transcripts/YYYY-MM-DD_HHMMSS_<모드>.<확장자>`에 저장되며, 타임코드는 자막을 시작한 시점부터 계산합니다.
설정 페이지에서 '끝날 때마다 자동 저장(SRT, TXT)'을 켤 수 있습니다. '중지'를 누르면 마지막 문장의 최종 자막이 도착할 때까지(최대 2초) 기다린 뒤 저장합니다.

### OBS 텍스트 파일

설정 페이지 '자막 기록과 OBS' → '자막을 텍스트 파일로 출력(OBS용)': 원문, 번역 또는 둘 다.
kikitori는 자막 창에 현재 표시된 문장을 `문서/kikitori/obs/subtitle.txt`에 덮어씁니다(UTF-8, 원자적 쓰기, 초당 최대 10회).
OBS에서 '텍스트 (GDI+)' 소스를 추가하고 '파일에서 불러들이기'를 체크한 뒤 이 파일을 지정하세요. 자막이 끝나거나, 유휴 상태로 페이드아웃되거나, 자막을 지우면 파일이 비워집니다.
네트워크 포트를 전혀 열지 않으므로 OBS '브라우저' 소스를 쓰는 방식은 없습니다.

### 전역 단축키

| Windows／Linux | macOS | 동작 |
|---|---|---|
| Ctrl+Alt+K | ⌘+Option+K | 자막 창의 클릭 통과 전환 |
| Ctrl+Alt+J | ⌘+Option+J | '번역 표시' 전환 |
| Ctrl+Alt+U | ⌘+Option+U | 자막 창(과 OBS 텍스트 파일) 지우기. 자막 기록에는 영향 없음 |
| Ctrl+Alt+P | ⌘+Option+P | 자막 창 일시 정지／다시 시작. 자막 기록은 평소대로 계속됨 |
| Ctrl+Alt+H | ⌘+Option+H | 자막 창에 최근 10문장을 잠시 표시 |
| Ctrl+Alt+R | ⌘+Option+R | 통역 중 자막 창에 상대의 언어로 '다시 말해 주세요'를 표시 |

다른 프로그램이 사용 중인 단축키는 자막 기록 페이지에 '쓸 수 없습니다'로 표시되며, 다른 단축키에는 영향을 주지 않습니다. Linux Wayland에서는 전역 단축키를 전혀 등록하지 못할 수 있습니다.

## 개인정보와 오프라인

- 소리, 인식 결과, 번역문은 모두 사용자의 컴퓨터에서만 처리됩니다. 번역은 기본적으로 로컬 Ollama(`http://localhost:11434/v1`)로 보냅니다. 번역 서비스를 다른 주소로 바꾸면 자막 텍스트가 그곳으로 전송됩니다.
- 네트워크에 연결하는 경우는 다음뿐입니다: 모델 다운로드(음성 인식 모델은 Hugging Face, 번역 모델은 Ollama를 통해, GPU 구성 요소는 PyPI에서 받으며 모두 '시작'이나 다운로드를 누를 때만 발생), 시작할 때 업데이트 확인(GitHub Releases). 모델을 모두 받은 뒤에는 자막 기능 자체를 완전히 오프라인으로 사용할 수 있습니다.
- API 키는 환경 변수에서만 읽으며(설정에는 변수 이름만 저장, 기본값 `KIKITORI_TRANSLATE_API_KEY`), 어떤 파일에도 쓰지 않습니다.
- '정보' 페이지의 '진단 정보 복사'는 클립보드에만 복사하며, 키, 주소에 포함된 계정 정보, 사용자 이름을 가리고 용어집은 항목 수만 표시합니다.
- 엔진과 데스크톱 앱은 표준 입출력으로만 통신하며 네트워크 포트를 열지 않습니다.

## 0.3.0 새 기능

요약(자세한 설명과 업그레이드 시 주의 사항은 [docs/release-notes/v0.3.0.md](docs/release-notes/v0.3.0.md), 0.2.0은 [docs/release-notes/v0.2.0.md](docs/release-notes/v0.2.0.md) 참고):

- 화자 라벨: 여러 명이 합방할 때 문장마다 '화자 1, 2…'를 표시. 인원 자동 판별 또는 2–6명 지정, 라벨을 클릭해 이름 변경, 같은 이름으로 바꾸면 합쳐짐(모델 약 27 MiB, 처음 선택할 때 다운로드)
- 실시간 번역문을 안정된 부분과 바뀌는 부분으로 나눠 문장 전체가 깜박이지 않음. 새 글자는 페이드인되고 자막이 위아래로 튀지 않음
- 통역 모드에서 '나／상대' 표시, Ctrl+Alt+R로 상대의 언어로 '다시 말해 주세요' 표시
- 인식 결과 수정 규칙, 자막 기록에서 고른 단어를 용어집에 추가, 이번 방송 정보(방송인 이름, 게임 이름, 방송 설명란)
- 읽기 레이아웃: 원문 크기와 위치, 줄 너비, 글자 수에 따라 표시 시간 연장, 후리가나는 처음 나올 때만
- 새 단축키 Ctrl+Alt+P 자막 일시 정지, Ctrl+Alt+H 최근 자막 다시 보기. 자막 창 위치 초기화, 배경음이 너무 크면 알림

## 알려진 제한 사항

- **완전한 실측은 Windows(RTX 5070)에서만 했습니다**. macOS와 Linux의 실제 기기 캡처, Apple Silicon과 CPU에서의 번역 속도는 측정하지 않았습니다. Linux는 Docker 컨테이너에서만 인수 테스트를 했습니다.
- **새 추천 구성은 RTX 5070(12 GB)에서만 엔드투엔드로 측정했습니다**: turbo＋large-v3(int8_float16)와 qwen3.5:9b를 동시에 실행할 때 그래픽 카드 전체 최대 10.8 GB, 실시간 자막 지연 약 0.31초, 말이 끝난 뒤 최종 자막까지 약 0.92초(중앙값, [`tasks/acceptance-report-v0.2.0.md`](tasks/acceptance-report-v0.2.0.md) 참고).
- **인식 정확도 평가 자료는 VTuber가 아닙니다**: YouTube의 일반 구어(YODAS), 낭독, TV 음성에 BGM을 섞은 것을 썼으며, 노래 방송, 비명, 여러 명의 합방 데이터는 없습니다. 노랫소리는 음성 감지를 통과하므로 이상한 자막이 나올 수 있습니다.
- **화자 라벨은 이어 붙인 YouTube 클립에서만 측정했습니다**(2명 약 92–100%, 3–4명 약 80–85% 정확): 말이 겹치는 경우, 1초 미만의 맞장구, 한 사람이 목소리를 바꾸는 경우의 데이터는 없어 실제 합방에서는 더 낮을 수 있습니다. OBS 텍스트 파일에는 기록하지 않습니다.
- 영어 외의 언어는 공개 벤치마크와 비음성 환각 테스트만 했고, 실제 음성으로는 실측하지 않았습니다. 환각 문구 목록은 원어민의 검토를 거치지 않았습니다.
- 일부 마무리 인사말(예: 'チャンネル登録よろしくお願いします')은 Whisper 환각으로 간주되어 문장 전체가 걸러집니다. 방송인이 실제로 말한 경우에도 마찬가지입니다.
- 번역하려면 Ollama를 따로 설치해야 합니다. Ollama 외의 OpenAI 호환 서버에서는 모델을 직접 설치해야 합니다.
- 장시간 실행 메모리 부하 테스트는 Windows에서 했습니다(엔진 20분 session 동안 일정, 메인 창 22분 동안 +0.7 MiB／분). macOS와 Linux에서는 테스트하지 않았습니다.
- 자막 session은 한 번에 하나만 실행할 수 있습니다. 장치가 분리되면 자동으로 다시 연결하지 않습니다.
- 지원하지 않음: 단어를 클릭해 사전 찾기, 특정 앱의 소리만 캡처, 노래 방송 모드, 한 문장 안에서 화자가 바뀌거나 여러 명이 동시에 말하는 경우의 분리, OBS '브라우저' 소스(이유는 [`docs/specs/competitive-features.md`](docs/specs/competitive-features.md)의 '당장은 하지 않음'(先不做) 절(중국어 문서)과 [`docs/adr/`](docs/adr/) 참고).
- 설치 파일에는 유료 코드 서명이 없습니다(Windows SmartScreen, macOS Gatekeeper가 경고합니다).
