# kikitori（聞き取り）

[繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [English](README.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md) | [Tiếng Việt](README.vi.md) | **ไทย** | [Bahasa Indonesia](README.id.md)

*เอกสารนี้แปลจาก README.zh-TW.md ภาษาจีนตัวเต็ม หากเนื้อหาไม่ตรงกัน ให้ยึด README.zh-TW.md เป็นหลัก แปลโดยใช้ AI ช่วย หากพบจุดที่ผิด ยินดีรับการแก้ไขผ่าน [issues](https://github.com/alianlbj23/kikitori/issues)*

kikitori ฟังเสียงที่คอมพิวเตอร์ของคุณกำลังเล่น (หรือไมโครโฟน) แล้วรู้จำเป็นข้อความแบบเรียลไทม์ แปลเป็นภาษาที่คุณเลือก และแสดงเป็นคำบรรยายสองภาษาที่ลอยอยู่บนหน้าจอ
การรู้จำเสียงพูด (Whisper) และการแปล (Ollama ในเครื่อง) ทำงานบนคอมพิวเตอร์ของคุณเองทั้งหมด เสียงและข้อความจะไม่ถูกอัปโหลดไปยังบริการคลาวด์ใด ๆ

กรณีใช้งานหลักคือ **การดูไลฟ์สตรีมของ VTuber ภาษาญี่ปุ่น** (มี BGM เสียงประกอบเกม และศัพท์เฉพาะของไลฟ์) โมเดลที่แนะนำและพารามิเตอร์ต่าง ๆ ได้รับการปรับตามผลการวัดจริงของโปรเจกต์นี้
ใช้กับการจับคู่ใด ๆ ระหว่าง 20 ภาษาได้เช่นกัน

- แพลตฟอร์ม: Windows 10/11 x64 (แพลตฟอร์มหลักที่ใช้ตรวจสอบ), Linux x64, macOS Apple Silicon
- สัญญาอนุญาต: MIT (แต่ละโมเดลมีสัญญาอนุญาตของตนเอง ดู "สัญญาอนุญาต")
- เวอร์ชันปัจจุบัน: 0.3.0 ([รายละเอียดการอัปเดต](docs/release-notes/v0.3.0.md))

## ฟีเจอร์

| ฟีเจอร์ | คำอธิบาย |
|---|---|
| แปลวิดีโอ | จับเสียงที่ระบบกำลังเล่น (Windows WASAPI loopback / Linux PulseAudio monitor / macOS ScreenCaptureKit) แล้วแปลจากภาษาที่ฟังเป็นภาษาคำบรรยาย |
| ล่ามแบบเรียลไทม์ | จับเสียงจากไมโครโฟน เมื่อคุณพูด "ภาษาของฉัน" จะแปลเป็นภาษาของอีกฝ่าย เมื่ออีกฝ่ายพูดจะแปลเป็นภาษาของคุณ |
| คำบรรยายสองเส้นทาง เร็วก่อนแล้วแม่นทีหลัง | ระหว่างที่ประโยคยังพูดไม่จบ จะใช้โมเดลที่เร็วกว่าแสดง "คำบรรยายแบบทันที" ก่อน พอพูดจบจะใช้โมเดลที่แม่นกว่าคำนวณ "คำบรรยายฉบับสมบูรณ์" ใหม่มาแทนที่ |
| คำบรรยายแบบทันทีที่นิ่ง | ทั้งต้นฉบับและคำแปลของคำบรรยายแบบทันที ส่วนต้นที่ไม่เปลี่ยนแล้วแสดงตามปกติ ส่วนท้ายที่ยังเปลี่ยนอยู่แสดงเป็นสีจาง ตัวอักษรใหม่จะค่อย ๆ ปรากฏขึ้น และทั้งก้อนจะไม่กระโดดขึ้นลงอีก |
| ป้ายชื่อผู้พูด | เมื่อคอลแลบหลายคน จะแสดง "ผู้พูด 1, 2…" หน้าแต่ละประโยค ระบุจำนวนคนอัตโนมัติหรือกำหนดเอง 2–6 คนได้ และคลิกป้ายชื่อเพื่อเปลี่ยนชื่อได้ ในโหมดล่ามจะแสดง "คุณ / อีกฝ่าย" |
| จับคู่ 20 ภาษาได้อิสระ | ภาษาที่ฟัง (เลือก "ตรวจหาอัตโนมัติ" ได้) และภาษาคำบรรยายเลือกได้อิสระจาก 20 ภาษา ดู "ภาษาที่รองรับ" |
| ภาษาอินเทอร์เฟซ 13 ภาษา | ค่าเริ่มต้นตามระบบปฏิบัติการ เปลี่ยนได้ที่หน้าการตั้งค่า |
| แสดงเฉพาะต้นฉบับ | ปิด "แสดงคำแปล" เพื่อดูเฉพาะต้นฉบับ: ไม่ต้องใช้ Ollama ไม่ใช้ GPU และสลับได้แม้ขณะทำงานอยู่ |
| ฟุริงานะ | แสดงคำอ่านบนคันจิในต้นฉบับภาษาญี่ปุ่น (SudachiDict ประมาณ 69 MiB ดาวน์โหลดเมื่อเปิดใช้ครั้งแรกเท่านั้น) |
| แนะนำโมเดลตามฮาร์ดแวร์ | ตรวจหา CPU หน่วยความจำ การ์ดจอ NVIDIA และ Ollama แล้วเลือกชุดโมเดลให้อัตโนมัติ ดาวน์โหลดโมเดลที่ขาดเมื่อกด "เริ่ม" ครั้งแรกเท่านั้น |
| อภิธานศัพท์ | มีศัพท์ไลฟ์สตรีมภาษาญี่ปุ่นในตัว 53 คำ (赤スパ, 推し, メン限…) และคำจีน–ญี่ปุ่นที่มักแปลผิดสำหรับการแปลจีนเป็นญี่ปุ่น เพิ่มรายการเองและนำเข้า/ส่งออก CSV ได้ |
| แก้ผลการรู้จำเสียงและข้อมูลไลฟ์ | แก้คำที่การรู้จำมักผิดให้ถูกโดยอัตโนมัติ กรอกชื่อสตรีมเมอร์ ชื่อเกม หรือคำอธิบายไลฟ์ เพื่อให้แปลชื่อได้ตรงกัน |
| ส่งออกข้อความถอดเสียง | SRT, VTT, TXT, CSV ตั้งให้บันทึกอัตโนมัติทุกครั้งที่จบได้ |
| ไฟล์ข้อความสำหรับ OBS | เขียนคำบรรยายปัจจุบันลงไฟล์ข้อความ เพื่อใช้กับตัวเลือก "อ่านจากไฟล์" ของแหล่ง "ข้อความ (GDI+)" ใน OBS โดยไม่เปิดพอร์ตเครือข่าย |
| หน้าต่างคำบรรยาย | โปร่งใส อยู่บนสุด ให้เมาส์คลิกทะลุได้ ปรับขนาดตัวอักษร พื้นหลัง ตำแหน่ง จำนวนประโยค เวลาแสดงขั้นต่ำของแต่ละประโยค เวลาว่างก่อนจางหาย ขนาดและตำแหน่งต้นฉบับ และความกว้างต่อบรรทัดได้ทั้งหมด หยุดชั่วคราวและดูคำบรรยายล่าสุดย้อนหลังได้ |
| แถบสถานะ | มาตรวัดระดับเสียง ความหน่วง (ค่ามัธยฐานตั้งแต่พูดจบจนได้คำบรรยายฉบับสมบูรณ์) แจ้งเตือนเมื่อการรู้จำตามไม่ทัน ไม่มีเสียงนาน 15 วินาที หรือเสียงพื้นหลังดังเกินไป |
| จัดการโมเดล | ดาวน์โหลด ดูพื้นที่ดิสก์ที่ใช้ และลบโมเดลรู้จำเสียง ดาวน์โหลดโมเดลแปลภาษาใน Ollama ให้คุณ |
| อัปเดตอัตโนมัติ | ตรวจสอบ GitHub Releases เมื่อเปิดโปรแกรม ดาวน์โหลดและตรวจสอบลายเซ็นแล้วจึงติดตั้ง |

ภาษาอินเทอร์เฟซ (13 ภาษา): 繁體中文（台灣）, 简体中文, English, 日本語, 한국어, Español, Français, Deutsch, Português (Brasil), Русский, Tiếng Việt, ไทย, Bahasa Indonesia
ภาษาอาหรับใช้เป็นภาษาที่ฟังหรือภาษาคำบรรยายได้ แต่ไม่มีอินเทอร์เฟซภาษาอาหรับ (อินเทอร์เฟซไม่รองรับเลย์เอาต์จากขวาไปซ้าย)

## ชุดที่แนะนำ (ตามฮาร์ดแวร์)

kikitori จะตรวจหาและนำไปใช้ให้อัตโนมัติ ตารางด้านล่างมีไว้ให้คุณรู้ว่าจะได้ชุดใด โดยอ้างอิงจากการประเมินของโปรเจกต์นี้ (`experiments/vtuber_eval/`, `experiments/translate_eval/`) กฎและสูตรดูได้ที่ [`docs/specs/hardware.md`](docs/specs/hardware.md)

| คอมพิวเตอร์ของคุณ | คำบรรยายแบบทันที | คำบรรยายฉบับสมบูรณ์ | การแปล (Ollama) |
|---|---|---|---|
| NVIDIA 16 GB ขึ้นไป | large-v3-turbo (float16) | large-v3 (float16) | qwen3.5:9b |
| NVIDIA 12 GB (เช่น RTX 5070) | large-v3-turbo (int8_float16) | large-v3 (int8_float16) | qwen3.5:9b |
| NVIDIA 8–11 GB | large-v3-turbo (เปลี่ยนเป็น small เมื่อหน่วยความจำการ์ดจอพอดีขั้นต่ำ 8 GB) | large-v3 (เลือก precision ตามหน่วยความจำการ์ดจอ) | qwen3.5:4b |
| NVIDIA 4–8 GB | base | large-v3-turbo | qwen3.5:4b |
| NVIDIA ต่ำกว่า 4 GB | base | small | qwen3.5:4b |
| ไม่มี GPU NVIDIA, RAM ≥ 16 GB, 5 คอร์ขึ้นไป | base (CPU) | small (CPU) | qwen3.5:4b |
| ไม่มี GPU NVIDIA, RAM น้อยกว่านี้หรือไม่เกิน 4 คอร์ | tiny (CPU) | base (CPU) | qwen3.5:4b |
| Mac (Apple Silicon) | base (CPU) | small (CPU) | ตามขนาดหน่วยความจำรวม (unified memory) (16 GB ใช้ qwen3.5:9b) |

- precision แบบ int8_float16 และ float16 ให้คุณภาพการรู้จำเท่ากันจากการวัดจริง (ต่างกันอย่างไม่มีนัยสำคัญ) เพียงแต่ใช้หน่วยความจำการ์ดจอประมาณครึ่งหนึ่ง เมื่อใช้การ์ดจอร่วมกับโมเดลแปลภาษา kikitori จะให้โมเดลแปลภาษาได้ใช้รุ่นที่ใหญ่กว่าหนึ่งระดับก่อน
- ขนาดดาวน์โหลดโมเดลรู้จำเสียง: large-v3-turbo 1.62 GB, large-v3 3.09 GB, small 487 MB, base 148 MB, tiny 78 MB โมเดลแปลภาษา: qwen3.5:9b ประมาณ 6.6 GB, qwen3.5:4b ประมาณ 3.3 GB
- GPU NVIDIA ต้องใช้ cuBLAS 12 (ประมาณ 570 MB) kikitori ไม่ได้รวมไว้ในตัวติดตั้ง แต่ดาวน์โหลดได้ในคลิกเดียวหลังยอมรับ NVIDIA EULA ที่หน้าโมเดล หากไม่ได้ติดตั้งจะใช้ CPU แทน
- เมื่อเซิร์ฟเวอร์แปลภาษาอยู่บนคอมพิวเตอร์เครื่องอื่น (ระยะไกล) จะไม่เลือกโมเดลแปลภาษาให้อัตโนมัติ โปรดเลือกเองที่หน้าโมเดล
- การแปลจะแนะนำ Qwen3.5 (Apache-2.0) ก่อนเสมอ: หากหน่วยความจำการ์ดจอพอใช้ 9B ไม่เช่นนั้นใช้ 4B การ์ดจอที่ไม่เกิน 4 GB หรือไม่มี GPU NVIDIA ก็ใช้ qwen3.5:4b เช่นกัน โดย Ollama จะย้ายส่วนที่ใส่ไม่พอไปทำงานบน CPU ซึ่งช้ากว่า (ยังไม่ได้วัดความหน่วงของการแปลในกรณีนี้)
- Tencent HY-MT มีข้อจำกัดด้านภูมิภาค จะถูกแนะนำได้ก็ต่อเมื่อคุณทำเครื่องหมาย "ฉันยืนยันว่าไม่ได้ใช้ kikitori ในสหภาพยุโรป สหราชอาณาจักร หรือเกาหลีใต้…" ที่หน้าการตั้งค่าแล้วเท่านั้น ส่วน Sakura (สัญญาอนุญาตที่ไม่ใช่เชิงพาณิชย์) จะไม่ถูกแนะนำเลย เลือกได้ด้วยตนเองเท่านั้น
- ความเร็วในการรู้จำบน macOS และ Linux รวมถึงความเร็วการแปลบน CPU ยังไม่ได้วัดจริง (ดู "ข้อจำกัดที่ทราบ")

## เริ่มต้นใช้งาน

1. ดาวน์โหลดตัวติดตั้งจาก [GitHub Releases](https://github.com/alianlbj23/kikitori/releases) (คำแนะนำการติดตั้งของแต่ละแพลตฟอร์มอยู่ในหน้า Release: คำเตือน SmartScreen / Gatekeeper เนื่องจากไม่มีลายเซ็น, fuse3 และฟอนต์บน Linux)
2. หากต้องการแปล ให้ติดตั้ง [Ollama](https://ollama.com/download) และปล่อยให้ทำงานอยู่เบื้องหลัง หาก kikitori ตรวจไม่พบจะแนะนำให้ "ติดตั้ง Ollama" หรือเปลี่ยนไปใช้ "แสดงเฉพาะต้นฉบับ"
3. เปิด kikitori การเปิดครั้งแรกจะนำชุดที่แนะนำตามฮาร์ดแวร์ไปใช้ให้อัตโนมัติ
4. เลือกภาษาที่ฟังและภาษาคำบรรยายในส่วน "ภาษา" ของหน้าการตั้งค่า หลังเลือกแล้วจะแสดงเพียงชุดที่แนะนำและขนาดดาวน์โหลด **ยังไม่ดาวน์โหลดทันที**
5. เลือกแหล่งเสียง แล้วกด "เริ่ม" โมเดลรู้จำเสียงและโมเดลแปลภาษา (เมื่อใช้ Ollama) ที่ขาดจะถูกดาวน์โหลดก่อน เสร็จแล้วจะเริ่มให้อัตโนมัติ

### แสดงเฉพาะต้นฉบับ

สวิตช์ "แสดงคำแปล" อยู่บนแถบเครื่องมือของหน้าข้อความถอดเสียง และในส่วน "คำบรรยาย" ของหน้าการตั้งค่า (หรือปุ่มลัด Ctrl+Alt+J) เมื่อปิด:

- เอนจินจะไม่เชื่อมต่อเซิร์ฟเวอร์แปลภาษาเลย ไม่ต้องติดตั้ง Ollama และไม่ใช้ GPU สำหรับโมเดลแปลภาษา
- หน้าต่างคำบรรยายจะแสดงต้นฉบับด้วยขนาดตัวอักษรและสีของคำบรรยายหลัก
- การสลับขณะทำงานมีผลทันที ประโยคที่แสดงไปแล้วจะไม่ถูกแปลย้อนหลัง

### ฟุริงานะ

"แสดงฟุริงานะบนต้นฉบับภาษาญี่ปุ่น" ในหน้าการตั้งค่า: เมื่อภาษาที่ฟังเป็นภาษาญี่ปุ่น จะแสดงคำอ่านเป็นฮิรางานะเหนือคันจิในต้นฉบับ (ไม่แสดงซ้ำในส่วนโอคุริงานะ) เมื่อเปิดใช้ครั้งแรกจะดาวน์โหลด SudachiDict core (Apache-2.0 ประมาณ 69 MiB) ดูพื้นที่ที่ใช้และลบได้ที่หน้าโมเดล มีผลเฉพาะการแสดงผล คำบรรยายที่ส่งออกไม่เปลี่ยน รายละเอียดการออกแบบดูที่ [`docs/specs/furigana.md`](docs/specs/furigana.md)

### อภิธานศัพท์

"อภิธานศัพท์" ในหน้าการตั้งค่า:

- **ตารางศัพท์ไลฟ์สตรีมในตัว** (เปิดเป็นค่าเริ่มต้น): ใช้เมื่อต้นฉบับเป็นภาษาญี่ปุ่นและคำบรรยายเป็นจีนตัวเต็ม / จีนตัวย่อ / อังกฤษ / เกาหลี เช่น คำบรรยายภาษาอังกฤษจะได้ スパチャ → Super Chat, メン限 → members-only, 切り抜き → clip โดยจะใส่ในพรอมต์การแปลเฉพาะคำที่ปรากฏจริงในต้นฉบับของประโยคนั้น (สูงสุด 8 รายการต่อประโยค)
- **คำจีน–ญี่ปุ่นที่มักแปลผิด** (เปิด/ปิดตามตารางในตัว): เมื่อต้นฉบับเป็นภาษาจีนและคำบรรยายเป็นภาษาญี่ปุ่น จะเตือนโมเดลถึงคำที่เขียนเหมือนหรือคล้ายกันในภาษาจีนและญี่ปุ่นแต่ความหมายต่างกัน เช่น 便當 → 弁当, 節目 → 番組, 老婆 → 妻 และการแปลจีนเป็นญี่ปุ่นจะเขียนคำสั่งถึงโมเดลเป็นภาษาจีนด้วย เพื่อลดการที่โมเดลอ่านภาษาจีนตามความหมายภาษาญี่ปุ่น
- **รายการกำหนดเอง**: ต้นฉบับ คำแปล และภาษาคำบรรยายที่ใช้ (หรือ "ทุกภาษา") สูงสุด 500 รายการ ใช้ได้กับภาษาที่ฟังทุกภาษา หากเขียนเหมือนกันจะมีลำดับความสำคัญเหนือตารางในตัว การเปรียบเทียบไม่แยกตัวพิมพ์ใหญ่/เล็กและอักขระเต็มความกว้าง/ครึ่งความกว้าง
- นำเข้า/ส่งออก CSV ได้ (UTF-8 คั่นด้วยจุลภาค อัฒภาค หรือ Tab อ่านไฟล์ที่บันทึกจาก Excel ได้) หลังกด "บันทึกอภิธานศัพท์" จะมีผลเมื่อเริ่มคำบรรยายครั้งถัดไป

### ส่งออกข้อความถอดเสียง

"ส่งออก" ในหน้าข้อความถอดเสียง: SRT, VTT, TXT, CSV เลือกเนื้อหาได้เป็น "ต้นฉบับและคำแปล" "เฉพาะต้นฉบับ" หรือ "เฉพาะคำแปล" ส่งออกเฉพาะคำบรรยายฉบับสมบูรณ์ (คำบรรยายแบบทันทียังเปลี่ยนแปลงอยู่)
ไฟล์จะถูกบันทึกที่ `เอกสาร/kikitori/transcripts/YYYY-MM-DD_HHMMSS_<โหมด>.<นามสกุล>` โดยไทม์โค้ดนับจากตอนเริ่มคำบรรยาย
ในหน้าการตั้งค่าสามารถเปิด "บันทึกอัตโนมัติทุกครั้งที่จบ (SRT และ TXT)" ได้ หลังกด "หยุด" จะรอให้คำบรรยายฉบับสมบูรณ์ของประโยคสุดท้ายมาถึง (สูงสุด 2 วินาที) แล้วจึงบันทึก

### ไฟล์ข้อความสำหรับ OBS

"ข้อความถอดเสียงและ OBS" → "เขียนคำบรรยายลงไฟล์ข้อความ (สำหรับ OBS)" ในหน้าการตั้งค่า: ต้นฉบับ คำแปล หรือทั้งสองอย่าง
kikitori จะเขียนทับประโยคที่แสดงอยู่ในหน้าต่างคำบรรยายลงใน `เอกสาร/kikitori/obs/subtitle.txt` (UTF-8 เขียนแบบอะตอมมิก สูงสุด 10 ครั้งต่อวินาที)
ใน OBS ให้เพิ่มแหล่ง "ข้อความ (GDI+)" แล้วทำเครื่องหมาย "อ่านจากไฟล์" ชี้ไปที่ไฟล์นี้ ไฟล์จะถูกล้างเมื่อคำบรรยายจบ จางหายเพราะไม่มีความเคลื่อนไหว หรือเมื่อล้างคำบรรยาย
ไม่เปิดพอร์ตเครือข่ายใด ๆ จึงไม่มีวิธีที่ใช้แหล่ง "เว็บเบราว์เซอร์" ของ OBS

### ปุ่มลัดส่วนกลาง

| Windows / Linux | macOS | การทำงาน |
|---|---|---|
| Ctrl+Alt+K | ⌘+Option+K | สลับการให้เมาส์คลิกทะลุหน้าต่างคำบรรยาย |
| Ctrl+Alt+J | ⌘+Option+J | สลับ "แสดงคำแปล" |
| Ctrl+Alt+U | ⌘+Option+U | ล้างหน้าต่างคำบรรยาย (และไฟล์ข้อความ OBS) โดยไม่กระทบข้อความถอดเสียง |
| Ctrl+Alt+P | ⌘+Option+P | หยุด / เล่นหน้าต่างคำบรรยายต่อ โดยข้อความถอดเสียงยังบันทึกตามปกติ |
| Ctrl+Alt+H | ⌘+Option+H | แสดง 10 ประโยคล่าสุดบนหน้าต่างคำบรรยายชั่วคราว |
| Ctrl+Alt+R | ⌘+Option+R | ระหว่างล่าม แสดง "กรุณาพูดอีกครั้ง" เป็นภาษาของอีกฝ่ายบนหน้าต่างคำบรรยาย |

ปุ่มลัดที่ถูกโปรแกรมอื่นใช้อยู่จะถูกระบุว่าใช้ไม่ได้ในหน้าข้อความถอดเสียง โดยไม่กระทบปุ่มลัดอื่น บน Linux Wayland อาจลงทะเบียนปุ่มลัดส่วนกลางไม่ได้เลย

## ความเป็นส่วนตัวและการใช้งานออฟไลน์

- เสียง ผลการรู้จำ และคำแปลจะถูกประมวลผลบนคอมพิวเตอร์ของคุณเท่านั้น โดยค่าเริ่มต้นการแปลจะส่งไปที่ Ollama ในเครื่อง (`http://localhost:11434/v1`) หากคุณเปลี่ยนบริการแปลเป็นที่อยู่อื่น ข้อความคำบรรยายจะถูกส่งไปที่นั่น
- สิ่งที่เชื่อมต่อเครือข่ายมีเพียง: การดาวน์โหลดโมเดล (โมเดลรู้จำเสียงจาก Hugging Face โมเดลแปลภาษาผ่าน Ollama และส่วนประกอบ GPU จาก PyPI ทั้งหมดเกิดขึ้นเมื่อคุณกดเริ่มหรือดาวน์โหลดเท่านั้น) และการตรวจสอบอัปเดตเมื่อเปิดโปรแกรม (GitHub Releases) เมื่อดาวน์โหลดโมเดลครบแล้ว ตัวคำบรรยายใช้งานแบบออฟไลน์ได้ทั้งหมด
- API key อ่านจากตัวแปรสภาพแวดล้อมเท่านั้น (การตั้งค่าเก็บเฉพาะชื่อตัวแปร ค่าเริ่มต้นคือ `KIKITORI_TRANSLATE_API_KEY`) และไม่ถูกเขียนลงไฟล์ใด ๆ
- "คัดลอกข้อมูลวินิจฉัย" ในหน้า "เกี่ยวกับ" คัดลอกไปที่คลิปบอร์ดเท่านั้น โดยปิดบังคีย์ บัญชีและรหัสผ่านใน URL และชื่อผู้ใช้ ส่วนอภิธานศัพท์แสดงเพียงจำนวนรายการ
- เอนจินกับโปรแกรมเดสก์ท็อปสื่อสารกันผ่านอินพุต/เอาต์พุตมาตรฐานเท่านั้น ไม่เปิดพอร์ตเครือข่าย

## ฟีเจอร์ใหม่ใน 0.3.0

สรุป (คำอธิบายฉบับเต็มและข้อควรระวังในการอัปเกรดดูที่ [docs/release-notes/v0.3.0.md](docs/release-notes/v0.3.0.md) ส่วน 0.2.0 ดูที่ [docs/release-notes/v0.2.0.md](docs/release-notes/v0.2.0.md)):

- ป้ายชื่อผู้พูด: เมื่อคอลแลบหลายคน แต่ละประโยคจะมีป้าย "ผู้พูด 1, 2…" ระบุจำนวนคนอัตโนมัติหรือกำหนดเอง 2–6 คน คลิกป้ายชื่อเพื่อเปลี่ยนชื่อ ถ้าตั้งชื่อซ้ำกันจะรวมเป็นป้ายเดียว (โมเดลประมาณ 27 MiB ดาวน์โหลดเมื่อเลือกใช้ครั้งแรก)
- คำแปลแบบทันทีแบ่งเป็นส่วนที่นิ่งและส่วนที่ยังเปลี่ยน ไม่กะพริบทั้งประโยคอีกต่อไป ตัวอักษรใหม่ค่อย ๆ ปรากฏขึ้น และคำบรรยายไม่กระโดดขึ้นลง
- โหมดล่ามแสดง "คุณ / อีกฝ่าย" และ Ctrl+Alt+R แสดง "กรุณาพูดอีกครั้ง" เป็นภาษาของอีกฝ่าย
- กฎแก้ผลการรู้จำเสียง เลือกคำจากข้อความถอดเสียงเพื่อเพิ่มลงอภิธานศัพท์ และข้อมูลไลฟ์นี้ (ชื่อสตรีมเมอร์ ชื่อเกม คำอธิบายไลฟ์)
- เลย์เอาต์การอ่าน: ขนาดและตำแหน่งต้นฉบับ ความกว้างต่อบรรทัด ยืดเวลาแสดงตามจำนวนตัวอักษร และใส่ฟุริงานะเฉพาะครั้งแรก
- ปุ่มลัดใหม่ Ctrl+Alt+P หยุดคำบรรยายชั่วคราว Ctrl+Alt+H ดูคำบรรยายล่าสุดย้อนหลัง รีเซ็ตตำแหน่งหน้าต่างคำบรรยาย และแจ้งเตือนเมื่อเสียงพื้นหลังดังเกินไป

## ข้อจำกัดที่ทราบ

- **ทดสอบจริงอย่างครบถ้วนบน Windows (RTX 5070) เท่านั้น** การจับเสียงบนเครื่องจริงของ macOS และ Linux รวมถึงความเร็วการแปลบน Apple Silicon และ CPU ยังไม่ได้วัด ส่วน Linux ผ่านการทดสอบรับรองในคอนเทนเนอร์ Docker เท่านั้น
- **ชุดที่แนะนำใหม่วัดแบบครบวงจรบน RTX 5070 (12 GB) เท่านั้น**: เมื่อ turbo + large-v3 (int8_float16) และ qwen3.5:9b ทำงานพร้อมกัน ทั้งการ์ดใช้สูงสุด 10.8 GB ความหน่วงของคำบรรยายแบบทันทีประมาณ 0.31 วินาที ตั้งแต่พูดจบจนได้คำบรรยายฉบับสมบูรณ์ประมาณ 0.92 วินาที (ค่ามัธยฐาน ดู [`tasks/acceptance-report-v0.2.0.md`](tasks/acceptance-report-v0.2.0.md))
- **ข้อมูลที่ใช้ประเมินความแม่นยำการรู้จำไม่ใช่ VTuber**: ใช้บทพูดทั่วไปบน YouTube (YODAS) เสียงอ่าน และเสียงจากโทรทัศน์ ผสม BGM เพิ่ม ไม่มีข้อมูลไลฟ์ร้องเพลง เสียงกรีดร้อง หรือคอลแลบหลายคน เสียงร้องเพลงจะเล็ดลอดผ่านตัวตรวจจับเสียงพูด และอาจทำให้เกิดคำบรรยายแปลก ๆ
- **ป้ายชื่อผู้พูดวัดผลบนคลิป YouTube ที่นำมาต่อกันเท่านั้น** (2 คนติดป้ายถูกประมาณ 92–100% และ 3–4 คนประมาณ 80–85%): ไม่มีข้อมูลการพูดแทรก เสียงรับคำที่สั้นกว่า 1 วินาที และคนเดียวเปลี่ยนน้ำเสียง จึงอาจแม่นยำน้อยกว่านี้ในคอลแลบจริง และไม่เขียนลงไฟล์ข้อความ OBS
- ภาษาอื่นนอกจากภาษาอังกฤษมีเพียงเกณฑ์มาตรฐานสาธารณะและการทดสอบภาพหลอนกับเสียงที่ไม่ใช่เสียงพูด ยังไม่ได้วัดกับเสียงพูดจริง และรายการวลีภาพหลอนยังไม่ผ่านการตรวจทานโดยเจ้าของภาษา
- ประโยคปิดท้ายบางประโยค (เช่น "チャンネル登録よろしくお願いします") จะถูกมองว่าเป็นภาพหลอนของ Whisper และถูกกรองทิ้งทั้งประโยค แม้สตรีมเมอร์จะพูดจริงก็ตาม
- ต้องติดตั้ง Ollama แยกต่างหากจึงจะแปลได้ สำหรับเซิร์ฟเวอร์ที่เข้ากันได้กับ OpenAI อื่นนอกจาก Ollama ต้องติดตั้งโมเดลเอง
- ทดสอบแรงกดดันหน่วยความจำขณะทำงานเป็นเวลานานบน Windows แล้ว (เซสชันของเอนจิน 20 นาทีคงที่ หน้าต่างหลัก 22 นาที +0.7 MiB/นาที) ยังไม่ได้ทดสอบบน macOS และ Linux
- มีเซสชันคำบรรยายได้ครั้งละหนึ่งเซสชันเท่านั้น และเมื่ออุปกรณ์ถูกถอดออกจะไม่เชื่อมต่อใหม่อัตโนมัติ
- ไม่รองรับ: คลิกคำเพื่อค้นหา จับเสียงเฉพาะแอปเดียว โหมดไลฟ์ร้องเพลง การแยกเสียงเมื่อเปลี่ยนผู้พูดกลางประโยคหรือหลายคนพูดพร้อมกัน และแหล่ง "เว็บเบราว์เซอร์" ของ OBS (เหตุผลดูที่หัวข้อ "ยังไม่ทำในตอนนี้" (先不做) ในเอกสารภาษาจีน [`docs/specs/competitive-features.md`](docs/specs/competitive-features.md) และ [`docs/adr/`](docs/adr/))
- ตัวติดตั้งไม่มีการลงนามโค้ดแบบเสียเงิน (Windows SmartScreen และ macOS Gatekeeper จะแสดงคำเตือน)
