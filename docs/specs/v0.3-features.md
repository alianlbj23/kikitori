# Spec: v0.3 改進（譯文穩定、閱讀與控制、口譯、術語）

> 上位文件：`docs/specs/competitive-features.md`（F1–F8 已在 0.2.0 完成）。依據：`reports/kikitori 功能與改進方向.md` 的路線圖「近期可做」
> 八項（S1、S2、I1、I2、N2、N1、U5、U1–U4、U6）。2026-11-08 使用者指示「照建議先做」；依專案記憶自主執行，做完再一起回報。
> 各模組規格（`pipeline-engine.md`、`translate.md`、`ui.md`）在實作時同步更新，本文件只列範圍、決策與驗收。

## Objective

0.2.0 的即時字幕只對**原文**算穩定前綴；即時譯文每次重翻都可能整行改寫。這一版先把譯文也穩住，再補上研究與官方規範指得出來、
成本低、不需要新依賴的閱讀與控制功能，以及口譯模式「誰說的」標示。所有項目都不新增 Python／npm／Rust 相依套件。

## 範圍與決策

### G1 即時譯文的穩定前綴（S1，引擎＋Rust＋UI）

- 依據：IWSLT 2026 Findings（同步翻譯前段系統用「串流 ASR＋現成 LLM＋LCP 前綴政策」）。
- 引擎（`pipeline/stability.py`）：同一句的即時譯文，以「上一則**完整**送出的即時譯文」與這則的最長共同前綴為譯文穩定前綴。
  - 串流途中：新譯文還是上一則的前綴時，畫面維持上一則（不縮短、不閃）；一旦超出或分歧才顯示新譯文。
  - `subtitle` 事件（只限即時字幕）多 `translation_stable_chars: int | None`：以 code point 計、≤ `len(translation)`；
    這句第一則為 0；不翻譯的路由（copy／off／unsupported）為 `min(stable_chars, len(translation))`（譯文就是原文或空）；完整字幕不帶。
  - 不多送任何翻譯請求；`should_translate` 規則不變。
- Rust：驗證並轉發（與 `stable_chars` 同樣的範圍檢查）。
- UI：即時譯文與原文一樣分成穩定（正常）與尾巴（淡色）；舊引擎沒有這個欄位時維持整句淡色。
- 量測：`kikitori.evaluation` 加 `normalized_erasure()`（Arivazhagan et al., ICASSP 2020：每次更新被刪掉的字數總和 ÷ 最終長度），
  e2e 驗收報告對原文與譯文各算一次。

### G2 不跳行＋新字淡入（S2，UI）

- 依據：Google CHI EA 2023（N=123，穩定化＋新字淡入 6 題項中 5 項顯著較佳）。
- 字幕視窗的即時字幕：同一句的高度只增不減（記錄這句出現過的最大高度當 `min-height`，完整字幕時解除），
  避免尾巴改字讓整塊上下跳。字幕紀錄是可捲動的清單、不是一眼掃過的字幕，維持現狀。
- 新出現在尾端的字（與同一句上一次畫面的共同前綴之後的部分）以 180 ms 淡入；`prefers-reduced-motion: reduce` 時不做動畫。
- 不改變文字內容，只改呈現。

### G3 口譯模式的說話者標示與「請再說一次」（I1、I2，引擎＋UI＋Rust）

- 引擎：口譯模式的 `subtitle` 事件多 `speaker: "self" | "partner"`（依路由：原文是「我的語言」為 self）；影片翻譯不帶這個欄位（Rust 與 UI 把缺少視為 null）。
- UI：字幕視窗在換說話者時於句首標「你」／「對方」（同一人連續說話不重複），字幕紀錄每一列都標；以顏色區分，但顏色不是唯一線索。
  匯出檔（TXT／SRT／VTT 加前綴，CSV 多一欄 `speaker`）帶同樣的標示；OBS 文字檔不加（口譯模式很少接 OBS，且 Rust 端沒有介面語系的字典）。
- 「請再說一次」：全域快速鍵 **Ctrl+Alt+R**（macOS ⌘+Option+R），只在口譯模式執行中有作用：在字幕視窗顯示一句預先寫好、
  以**對方的語言**寫的「抱歉，可以請你再說一次嗎？」（20 種語言的固定譯文表 `src/locales/phrases/say-again.ts`，不呼叫翻譯），顯示 5 秒。
  不記進字幕紀錄（字幕紀錄只放引擎辨識出的句子，插入本機產生的列會與 `utterance_id` 的排序衝突）。

### G4 從字幕紀錄加入術語表、原文校正（N2，UI＋引擎）

- 字幕紀錄頁：選取一句原文中的文字後，出現「加入術語表」按鈕 → 切到術語表並新增一列，原文預填選取的文字、譯文語言預填目前字幕語言，
  游標停在譯文欄。
- 術語表頁新增「原文校正」區（文字框，每行一筆 `錯的寫法 => 正確寫法`），最多 200 筆，套用在**辨識結果**（顯示的原文、翻譯的輸入、
  字幕紀錄）上，純字串替換（不分大小寫與全形／半形，與術語表相同的比對規則）、最長優先、不連鎖替換。設定存在
  `translation.glossary.corrections`（引擎驗證：每筆 1–100 字元、去頭尾空白、兩邊不能完全相同、錯的寫法不重複）。下一次開始字幕時生效。
- CSV 匯入／匯出只處理術語表，不含校正（保持既有格式）。

### G5 本場直播資訊（N1，UI＋引擎）

- 依據：IWSLT 2026 Extra Context（給系統相關文件後幾乎所有系統受益；UPV 平均 +2.75 COMET，增益集中在專有實體）。
- 主視窗左欄（「開始」按鈕上方）新增「本場資訊」文字欄（選填，最多 500 字元）：可以填主播名、遊戲名、連動成員，或貼上直播說明欄。
- 引擎把它放進翻譯請求的 user 訊息（前文之前），標「本場資訊（只供參考，不要翻譯）」；system prompt 不變（prompt cache 仍可命中）。
  即時與完整路徑都帶；只有 generic 格式（預設的 Qwen3.5）使用，HY-MT／Sakura 照官方範本不加。前文保險（context guard）也要能偵測模型把本場資訊翻出來的情況。
- 存在 `translation.session_info`（字串，引擎去頭尾空白、移除換行以外的控制字元、截到 500 字元）；跨 session 保留，按清除鈕才清空。
- 不做自動實體抽取（N3 留到之後）。

### G6 字幕視窗控制（U5，UI＋Rust）

- 「重設字幕視窗位置」按鈕（設定頁字幕區）：把字幕視窗移回主螢幕預設位置與大小並顯示；解決視窗卡在已拔掉的螢幕外。
- 「暫停字幕」全域快速鍵 **Ctrl+Alt+P**：字幕視窗凍結目前畫面並顯示「已暫停」小標；引擎、字幕紀錄、OBS 照常；再按一次恢復並立刻跳到最新。
- 「展開最近字幕」全域快速鍵 **Ctrl+Alt+H**：字幕視窗暫時顯示最近 10 句完整字幕（可捲動），8 秒或再按一次後收回。
- 快速鍵被占用時與既有快速鍵相同處理（字幕紀錄頁標示無法使用）。

### G7 閱讀版面（U1–U4，UI＋Rust）

- U1 依字數延長最短顯示：新設定「依字數延長顯示時間」（預設關）。開啟時每句最短顯示 = max(`min_display_ms`, 字數 ÷ cps)，
  cps：字幕語言為日、中、韓時 4（Netflix 日文規範），其他語言 15；仍遵守「等待不得累積成延遲」（既有 rhythm 規則）。
- U2 最大行寬：新設定「每行最多（字寬 em）」，0 = 不限（預設）；字幕視窗的文字區 `max-width` 以 em 計，置中。
- U3 振假名只標第一次：振假名設定多「只標本場第一次出現的詞」（預設關）；只影響字幕視窗（字幕紀錄照舊全標）。
- U4 原文大小與位置：新設定「原文大小（相對譯文）」50–150%（預設 62%，等於現行）與「原文位置：上／下」（預設上）。
- 這些都在 `settings.subtitle`（字幕視窗樣式：`pace_by_length`、`max_line_em`、`original_scale_percent`、`original_position`、`furigana_first_only`），
  Rust `OverlayStyle` 同步加欄位與範圍驗證；舊設定沒有的欄位用預設值。

### G8 背景音太大聲提示（U6，引擎＋UI）

- 引擎的 `metrics` 事件多 `speech_level_dbfs` 與 `background_level_dbfs`：最近約 10 秒內 VAD 判為語音／非語音的音訊 RMS（沒有樣本為 null）。
- UI：兩者都有值、`background_level_dbfs` 高於 −30 dBFS 且與語音相差不到 6 dB、持續 15 秒時，狀態列提示「背景音（BGM）很大聲，辨識可能變差」；
  條件解除後收起（沿用既有提醒的顯示方式）。門檻是推論值，標註於 `ui.md`，之後以 vtuber_eval 調整。

## 相容性

- 協定：新增的欄位都是選填；舊 UI 忽略、舊引擎不送時 UI 維持現行行為。協定版本不變（只加欄位）。
- 設定：`settings.subtitle` 新欄位有預設值；`translation.session_info`、`translation.glossary.corrections` 缺少時為空。
  schema 版本照 `config/settings.py` 的遷移規則處理（只加欄位，不需遷移）。
