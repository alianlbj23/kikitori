# kikitori 架構總覽

## 專案目標

kikitori 即時擷取電腦正在播放的聲音，把日文或英文語音翻譯成繁體中文。
畫面上同時顯示原文與譯文的雙語字幕，幫助語言學習者邊聽邊對照。
支援 Windows、Linux、macOS。

## 處理流程

```text
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ 音訊擷取 │ → │ VAD 切句 │ → │ 語音辨識 │ → │   翻譯   │ → │ 字幕顯示 │
└──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘
 系統播放的      偵測人聲，       日文/英文       翻譯成         原文與譯文
 聲音            切成一句一句     轉成文字        繁體中文       雙語字幕
```
