# ADR-0003：暫不做「歌回模式」（歌聲分類）

## 狀態

已採用（Accepted）。2026-11-06 使用者授權依建議決定。

## 日期

2026-11-06

## 背景

VTuber 的歌回（唱歌直播）中，Whisper 辨識歌詞不可靠，翻譯也容易產生幻覺。競品比較（`research_notes/競品比較/commercial_products.md` 第 9 項）建議：偵測到持續歌唱時顯示「♪」、不送去翻譯，並且「MUSAN 音樂段落非空字幕維持 0 句、歌唱段落的幻覺率要有量測值」。

## 決策

這一版不做歌聲分類器。

## 理由

- **分類器授權未確認**：可用的音訊分類模型（例如 CED）的權重授權還沒確認能和 MIT 一起散布；能直接用 ONNX 跑、不需要 PyTorch 的版本也還沒找到官方來源。
- **沒有評測資料**：沒有標註過的歌回音軌，無法量「歌唱段落的幻覺率」，也無法證明分類器的誤判（把說話當歌唱而吞掉字幕）比現狀少。
- **現有保護已涵蓋一部分**：
  - 純音樂段落：VAD＋幻覺片語過濾在驗收中是 0 句誤觸發。
  - BGM 下的說話：完整辨識改用 large-v3，比 turbo 更穩（`docs/specs/vtuber-profile.md`）。
- **想看原文的使用者已有替代做法**：「只顯示原文」可以關掉翻譯，避開翻譯的幻覺。

## 重新考慮的條件

以下兩項都成立時重新評估：

- 找到授權可商用、有 ONNX 權重的歌聲／音樂分類模型。
- 有授權可用的歌回評測音軌（含逐段的歌唱／說話標註）。
