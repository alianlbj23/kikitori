# kikitori v0.3.1

A small update that makes two common setup problems easier to fix. For everything new in 0.3, see `docs/release-notes/v0.3.0.md`.

## Improvements

- **Reminder to download the GPU acceleration component**: on a computer with an NVIDIA graphics card, speech recognition runs on the CPU (slower) until NVIDIA's GPU acceleration component is downloaded. kikitori now shows a reminder when it starts:
  - **Go to Models** jumps straight to the component on the Models page, where you accept the NVIDIA license and download it.
  - **Don't remind me** hides it for good; closing it hides it until the next launch.
  - It goes away by itself once the component is downloaded.
- **"Ollama is too old" is now explained**: when the Ollama on your computer is too old to download the recommended translation model, kikitori used to show Ollama's raw error ("pull model manifest: 412 … requires a newer version of Ollama"). It now tells you to update Ollama from https://ollama.com/download and press Retry. On Linux you can update with `curl -fsSL https://ollama.com/install.sh | sh`.

## Upgrading

- Your settings carry over; nothing to set up again.
