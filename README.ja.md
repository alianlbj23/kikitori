# kikitori（聞き取り）

[繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [English](README.md) | **日本語** | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md) | [Tiếng Việt](README.vi.md) | [ไทย](README.th.md) | [Bahasa Indonesia](README.id.md)

*これは繁体字中国語版 [README.zh-TW.md](README.zh-TW.md) の翻訳です。内容が異なる場合は README.zh-TW.md が優先されます。この翻訳は AI の支援を受けて作成したもので、誤りの指摘は [issues](https://github.com/alianlbj23/kikitori/issues) で歓迎します。*

kikitori は、パソコンで再生中の音声（またはマイク）を聞き取り、リアルタイムで文字に起こして選んだ言語に翻訳し、画面上に浮かぶ二言語字幕として表示します。
音声認識（Whisper）と翻訳（ローカルの Ollama）はどちらも自分のパソコン上で動作します。音声や文字がクラウドサービスに送られることはありません。

主な用途は**日本語の VTuber 配信の視聴**（BGM、ゲーム効果音、配信用語あり）で、推奨モデルとパラメータは本プロジェクトの実測に基づいて調整しています。
20 言語のそのほかの組み合わせにも対応します。

- 対応プラットフォーム：Windows 10/11 x64（主な検証環境）、Linux x64。macOS（Apple Silicon）は実機でまだ検証していないため、当面インストーラーを提供しません。
- ライセンス：MIT（各モデルには別のライセンスがあります。「ライセンス」を参照）
- 現在のバージョン：0.3.1（[更新内容](docs/release-notes/v0.3.1.md)）

## 機能

| 機能 | 説明 |
|---|---|
| 動画翻訳 | システムで再生中の音声をキャプチャし（Windows WASAPI loopback／Linux PulseAudio monitor／macOS ScreenCaptureKit）、聞き取る言語を字幕の言語に翻訳 |
| リアルタイム通訳 | マイクをキャプチャ。自分が「自分の言語」で話すと相手の言語に、相手が話すと自分の言語に翻訳 |
| 速さと正確さを両立する二段構えの字幕 | 話している途中は速いモデルで「リアルタイム字幕」を出し、話し終えたら正確なモデルで計算し直した「確定字幕」に置き換え |
| 安定したリアルタイム字幕 | リアルタイム字幕の原文と訳文のうち、もう変わらない先頭部分は通常表示、まだ変わる末尾は薄い色で表示。新しく出た文字はフェードインし、字幕全体が上下に跳ねない |
| 話者ラベル | 複数人のコラボで各文の前に「話者 1、2…」を表示。人数は自動判定または 2–6 人を指定でき、ラベルをクリックすると名前を変更できる。通訳モードでは「あなた／相手」を表示 |
| 20 言語の任意の組み合わせ | 聞き取る言語（「自動検出」も可）と字幕の言語を 20 言語から自由に選択。「対応言語」を参照 |
| 13 の UI 言語 | 既定では OS の言語に従い、設定ページで切り替え可能 |
| 原文のみ表示 | 「翻訳を表示」をオフにすると原文だけを表示。Ollama 不要、GPU も使わない。実行中も切り替え可能 |
| ふりがな | 日本語の原文の漢字に読みを表示（SudachiDict。初めてオンにしたときに約 69 MiB をダウンロード） |
| ハードウェアに応じたモデル推奨 | CPU、メモリ、NVIDIA GPU、Ollama を検出してモデル構成を自動選択。足りないモデルは初めて「開始」を押したときにダウンロード |
| 用語集 | 日本語の配信用語 53 語（赤スパ、推し、メン限…）と中→日翻訳で間違えやすい日中の同形語を内蔵。独自の項目の追加や CSV のインポート／エクスポートも可能 |
| 認識結果の修正とこの配信の情報 | 認識でよく間違える語を自動で正しく修正。配信者名、ゲーム名、配信の概要欄を入力すると名前の訳が統一される |
| 字幕履歴のエクスポート | SRT、VTT、TXT、CSV。終了するたびに自動保存する設定も可能 |
| OBS 用テキストファイル | 現在の字幕をテキストファイルに書き出し、OBS の「テキスト (GDI+)」ソースの「ファイルからの読み取り」で使える。ネットワークポートは開かない |
| 字幕ウィンドウ | 透明、最前面、クリック透過に対応。文字サイズ、背景、位置、文の数、1 文の最短表示時間、フェードアウトまでの待ち時間、原文の大きさと位置、1 行の幅を調整可能。一時停止や最近の字幕の振り返りも可能 |
| ステータスバー | 音量メーター、遅延（話し終えてから確定字幕までの中央値）。認識が追いつかないとき、15 秒間音声がないとき、背景音が大きすぎるときに通知 |
| モデル管理 | 音声認識モデルのダウンロード、ディスク使用量の確認、削除。翻訳モデルは Ollama へのダウンロードを代行 |
| 自動更新 | 起動時に GitHub Releases を確認し、ダウンロードして署名を検証してからインストール |

## 対応言語

聞き取る言語と字幕の言語（20 言語、任意の組み合わせ）：

| | | | | |
|---|---|---|---|---|
| 日本語 | English | 繁體中文（台灣） | 简体中文 | 한국어 |
| Español | Français | Deutsch | Português | Русский |
| Italiano | العربية | हिन्दी | Bahasa Indonesia | Tiếng Việt |
| ไทย | Türkçe | Polski | Nederlands | Українська |

- 繁体字中国語の字幕は OpenCC `s2twp` で台湾の正体字と台湾の言い回しに変換します（例：视频 → 影片）。変換するのは訳文に簡体字が含まれるときだけで、「台灣」を「臺灣」に変えることはありません。
- 聞き取る言語と字幕の言語が同じときは翻訳しません（繁体字と簡体字の間は字形の変換のみ）。
- 音声認識の品質は言語によって異なります。モデルのある言語での誤り率が 20% を超える場合（例：large-v3-turbo のタイ語・アラビア語・ヒンディー語、large-v3 のベトナム語）、推奨の説明に「認識品質が低め」と表示されます。タイ語・アラビア語・ヒンディー語では、8 GB 以上の GPU ならリアルタイム字幕にも large-v3 を使います。

UI 言語（13 言語）：繁體中文（台灣）、简体中文、English、日本語、한국어、Español、Français、Deutsch、Português (Brasil)、Русский、Tiếng Việt、ไทย、Bahasa Indonesia。
アラビア語は聞き取る言語や字幕の言語として使えますが、アラビア語の UI はありません（UI が右から左へのレイアウトに対応していないため）。

## 推奨構成（ハードウェア別）

kikitori が自動で検出して適用します。下の表は、どの構成になるかの目安です。根拠は本プロジェクトの評価（`experiments/vtuber_eval/`、`experiments/translate_eval/`）で、ルールと計算式は [`docs/specs/hardware.md`](docs/specs/hardware.md) を参照してください。

| お使いのパソコン | リアルタイム字幕 | 確定字幕 | 翻訳（Ollama） |
|---|---|---|---|
| NVIDIA 16 GB 以上 | large-v3-turbo（float16） | large-v3（float16） | qwen3.5:9b |
| NVIDIA 12 GB（例：RTX 5070） | large-v3-turbo（int8_float16） | large-v3（int8_float16） | qwen3.5:9b |
| NVIDIA 8–11 GB | large-v3-turbo（VRAM がちょうど下限の 8 GB なら small） | large-v3（VRAM に応じて精度を選択） | qwen3.5:4b |
| NVIDIA 4–8 GB | base | large-v3-turbo | qwen3.5:4b |
| NVIDIA 4 GB 未満 | base | small | qwen3.5:4b |
| NVIDIA GPU なし、RAM ≥ 16 GB、5 コア以上 | base（CPU） | small（CPU） | qwen3.5:4b |
| NVIDIA GPU なし、RAM が少ないか 4 コア以下 | tiny（CPU） | base（CPU） | qwen3.5:4b |
| Mac（Apple Silicon） | base（CPU） | small（CPU） | ユニファイドメモリの容量次第（16 GB なら qwen3.5:9b） |

- 精度 int8_float16 と float16 の認識品質は実測で同等（有意差なし）で、VRAM 使用量がおよそ半分になるだけです。翻訳モデルと GPU を共有する場合、kikitori は翻訳モデルを一段大きくすることを優先します。
- 音声認識モデルのダウンロードサイズ：large-v3-turbo 1.62 GB、large-v3 3.09 GB、small 487 MB、base 148 MB、tiny 78 MB。翻訳モデル：qwen3.5:9b 約 6.6 GB、qwen3.5:4b 約 3.3 GB。
- NVIDIA GPU には cuBLAS 12（約 570 MB）が必要です。kikitori のインストーラーには含まれておらず、「モデル」ページで NVIDIA EULA に同意するとワンクリックでダウンロードできます。インストールされていない場合は CPU を使います。
- 翻訳サーバーが別のパソコン（リモート）にある場合、翻訳モデルは自動選択されません。「モデル」ページで自分で選んでください。
- 翻訳には常に Qwen3.5（Apache-2.0）を優先して推奨します。VRAM が足りれば 9B、足りなければ 4B です。GPU が 4 GB 以下か NVIDIA GPU がない場合も qwen3.5:4b で、収まらない部分は Ollama が CPU で実行するため遅くなります（この場合の翻訳遅延はまだ実測していません）。
- Tencent HY-MT には地域制限があり、設定ページで「EU、英国、韓国で kikitori を使用しないことを確認し…」にチェックを入れた場合にのみ推奨される可能性があります。Sakura（非商用ライセンス）は推奨されることはなく、手動でのみ選べます。
- macOS と Linux での認識速度、CPU での翻訳速度はまだ実測していません（「既知の制限」を参照）。

## はじめに

1. [GitHub Releases](https://github.com/alianlbj23/kikitori/releases) からインストーラーをダウンロードします（各プラットフォームのインストール時の注意は Release ページに記載：未署名による SmartScreen／Gatekeeper の警告、Linux の fuse3 とフォント）。
2. 翻訳を使う場合は [Ollama](https://ollama.com/download) をインストールし、バックグラウンドで動かしておきます。kikitori が Ollama を検出できないときは「Ollama をインストール」または「原文のみ表示」を案内します。
3. kikitori を起動します。初回起動時にハードウェアに応じた推奨構成が自動で適用されます。
4. 設定ページの「言語」で、聞き取る言語と字幕の言語を選びます。選んだ時点では推奨構成とダウンロードサイズが表示されるだけで、**すぐにはダウンロードしません**。
5. 音声ソースを選び、「開始」を押します。足りない音声認識モデルと翻訳モデル（Ollama の場合）を先にダウンロードし、完了すると自動で開始します。

### 原文のみ表示

字幕履歴ページのツールバーと、設定ページの「字幕」欄にある「翻訳を表示」スイッチ（またはショートカット Ctrl+Alt+J）で切り替えます。オフのとき：

- エンジンは翻訳サーバーに一切接続しません。Ollama のインストールは不要で、翻訳モデルのために GPU を使うこともありません。
- 字幕ウィンドウでは原文がメイン字幕の文字サイズと色で表示されます。
- 実行中の切り替えはすぐに反映され、表示済みの文が後から翻訳されることはありません。

### ふりがな

設定ページの「日本語の原文にふりがなを表示」：聞き取る言語が日本語のとき、原文の漢字の上にひらがなで読みを表示します（送り仮名には振りません）。初めてオンにしたときに SudachiDict core（Apache-2.0、約 69 MiB）をダウンロードし、「モデル」ページで使用量の確認と削除ができます。変わるのは表示だけで、エクスポートする字幕は変わりません。設計は [`docs/specs/furigana.md`](docs/specs/furigana.md) を参照してください。

### 用語集

設定ページの「用語集」：

- **内蔵の配信用語集**（既定でオン）：原文が日本語で、字幕が繁体字中国語／簡体字中国語／英語／韓国語のときに使います。例えば繁体字中国語の字幕では スパチャ → 超級留言、メン限 → 會員專屬、切り抜き → 精華剪輯 と訳します。翻訳プロンプトに入れるのは、その文の原文に実際に出てくる語だけです（1 文につき最大 8 件）。
- **日中で間違えやすい語**（内蔵用語集のスイッチに連動）：原文が中国語で字幕が日本語のとき、中国語と日本語で表記が同じか似ていて意味が異なる語を示します。例：便當 → 弁当、節目 → 番組、老婆 → 妻。中→日翻訳ではモデルへの指示も中国語で書き、モデルが中国語を日本語の意味で読んでしまうことを減らします。
- **自分で追加した項目**：原文、訳文、適用する字幕の言語（または「すべての言語」）を指定します。最大 500 件で、聞き取る言語を問わず使えます。同じ表記の場合は内蔵の用語集より優先されます。照合では大文字と小文字、全角と半角を区別しません。
- CSV のインポート／エクスポートができます（UTF-8、区切りはカンマ・セミコロン・タブ。Excel で保存したファイルも読めます）。「用語集を保存」を押すと、次に字幕を開始したときから反映されます。

### 字幕履歴のエクスポート

字幕履歴ページの「エクスポート」：SRT、VTT、TXT、CSV に対応し、内容は「原文と訳文」「原文のみ」「訳文のみ」から選べます。エクスポートされるのは確定字幕だけです（リアルタイム字幕はまだ変わるため）。
ファイルは `ドキュメント/kikitori/transcripts/YYYY-MM-DD_HHMMSS_<モード>.<拡張子>` に保存され、タイムコードは字幕を開始した時点から数えます。
設定ページで「終了するたびに自動保存（SRT と TXT）」をオンにできます。「停止」を押すと、最後の文の確定字幕が届くのを待ってから（最大 2 秒）保存します。

### OBS 用テキストファイル

設定ページの「字幕履歴と OBS」→「字幕をテキストファイルに出力（OBS 用）」：原文、訳文、またはその両方を出力します。
kikitori は字幕ウィンドウに表示中の文を `ドキュメント/kikitori/obs/subtitle.txt` に上書きします（UTF-8、アトミック書き込み、毎秒最大 10 回）。
OBS で「テキスト (GDI+)」ソースを追加し、「ファイルからの読み取り」をオンにしてこのファイルを指定してください。字幕の終了時、無操作によるフェードアウト時、字幕の消去時にはファイルが空になります。
ネットワークポートを一切開かないため、OBS の「ブラウザ」ソースを使う方法はありません。

### グローバルショートカット

| Windows／Linux | macOS | 動作 |
|---|---|---|
| Ctrl+Alt+K | ⌘+Option+K | 字幕ウィンドウのクリック透過を切り替え |
| Ctrl+Alt+J | ⌘+Option+J | 「翻訳を表示」を切り替え |
| Ctrl+Alt+U | ⌘+Option+U | 字幕ウィンドウ（と OBS 用テキストファイル）を消去。字幕履歴には影響なし |
| Ctrl+Alt+P | ⌘+Option+P | 字幕ウィンドウを一時停止／再開。字幕履歴は通常どおり記録 |
| Ctrl+Alt+H | ⌘+Option+H | 字幕ウィンドウに直近 10 文を一時的に表示 |
| Ctrl+Alt+R | ⌘+Option+R | 通訳中、字幕ウィンドウに相手の言語で「もう一度言ってください」を表示 |

他のアプリが使用しているショートカットは、字幕履歴ページに「使えません」と表示されます。他のショートカットには影響しません。Linux の Wayland ではグローバルショートカットをまったく登録できない場合があります。

## プライバシーとオフライン

- 音声、認識結果、訳文はすべて自分のパソコン上で処理されます。翻訳は既定でローカルの Ollama（`http://localhost:11434/v1`）に送られます。翻訳サービスを別の URL に変更した場合は、字幕のテキストがそこへ送られます。
- ネットワークに接続するのは次の場合だけです：モデルのダウンロード（音声認識モデルは Hugging Face から、翻訳モデルは Ollama 経由で、GPU コンポーネントは PyPI から。いずれも「開始」やダウンロードを押したときのみ）、起動時の更新確認（GitHub Releases）。モデルがそろえば、字幕自体は完全にオフラインで使えます。
- API キーは環境変数からのみ読み取ります（設定には変数名だけを保存。既定は `KIKITORI_TRANSLATE_API_KEY`）。どのファイルにも書き込みません。
- 「バージョン情報」ページの「診断情報をコピー」はクリップボードにコピーするだけで、キー、URL 中の認証情報、ユーザー名は伏せられ、用語集は件数のみが記載されます。
- エンジンとデスクトップアプリの間は標準入出力だけで通信し、ネットワークポートは開きません。

## 0.3.0 の新機能

概要（詳しい説明とアップグレード時の注意は [docs/release-notes/v0.3.0.md](docs/release-notes/v0.3.0.md)、0.2.0 は [docs/release-notes/v0.2.0.md](docs/release-notes/v0.2.0.md) を参照）：

- 話者ラベル：複数人のコラボで各文に「話者 1、2…」を表示。人数は自動判定または 2–6 人を指定、ラベルをクリックして名前を変更、同じ名前にすると統合（モデルは約 27 MiB、初めて選んだときにダウンロード）
- リアルタイムの訳文を安定部分と変動部分に分け、文全体がちらつかなくなった。新しい文字はフェードインし、字幕が上下に跳ねない
- 通訳モードで「あなた／相手」を表示、Ctrl+Alt+R で相手の言語で「もう一度言ってください」を表示
- 認識結果の修正ルール、字幕履歴から選んだ語を用語集に追加、この配信の情報（配信者名、ゲーム名、配信の概要欄）
- 読みやすい表示：原文の大きさと位置、1 行の幅、文字数に応じて表示時間を延長、ふりがなは初出だけ
- 新しいショートカット Ctrl+Alt+P で字幕を一時停止、Ctrl+Alt+H で最近の字幕を振り返り。字幕ウィンドウの位置のリセット、背景音が大きすぎるときの通知

## 既知の制限

- **完全な実測は Windows（RTX 5070）でのみ実施**。macOS と Linux での実機キャプチャ、Apple Silicon と CPU での翻訳速度は測定していません。Linux は Docker コンテナ内での受け入れテストのみです。
- **新しい推奨構成のエンドツーエンド測定は RTX 5070（12 GB）のみ**：turbo＋large-v3（int8_float16）と qwen3.5:9b を同時に動かしたとき、GPU 全体で最大 10.8 GB、リアルタイム字幕の遅延は約 0.31 秒、話し終えてから確定字幕までは約 0.92 秒（中央値。[`tasks/acceptance-report-v0.2.0.md`](tasks/acceptance-report-v0.2.0.md) を参照）。
- **認識精度の評価素材は VTuber ではありません**：YouTube の一般的な話し言葉（YODAS）、朗読、テレビ音声に BGM を混ぜたものを使っており、歌枠、絶叫、複数人のコラボのデータはありません。歌声は音声区間検出をすり抜けるため、おかしな字幕が出ることがあります。
- **話者ラベルはつなぎ合わせた YouTube の切り抜きでのみ測定**（2 人で約 92–100%、3–4 人で約 80–85% が正しくラベル付け）：話がかぶる場面、1 秒未満の相づち、同じ人が声色を切り替えるデータはないため、実際のコラボでは精度が下がる可能性があります。OBS 用テキストファイルには書き出しません。
- 英語以外の言語は、公開ベンチマークと非音声でのハルシネーションテストのみで、実際の音声では実測していません。ハルシネーションのフレーズ表はネイティブスピーカーのレビューを受けていません。
- 一部の締めの定型句（例：「チャンネル登録よろしくお願いします」）は Whisper のハルシネーションとみなされ、配信者が本当に言った場合でも文ごと除去されます。
- 翻訳には Ollama を別途インストールする必要があります。Ollama 以外の OpenAI 互換サーバーでは、モデルを自分でインストールする必要があります。
- 長時間実行のメモリ負荷テストは Windows で実施済みです（エンジンは 20 分の session で横ばい、メインウィンドウは 22 分で +0.7 MiB／分）。macOS と Linux ではテストしていません。
- 字幕の session は同時に 1 つだけです。デバイスが抜かれても自動では再接続しません。
- 非対応：クリックでの単語検索、特定アプリだけの音声キャプチャ、歌枠モード、一文の途中での話者交代や複数人の同時発話の分離、OBS の「ブラウザ」ソース（理由は [`docs/specs/competitive-features.md`](docs/specs/competitive-features.md) の「今は実装しない」（先不做）の節（中国語の文書）と [`docs/adr/`](docs/adr/) を参照）。
- インストーラーには有料のコード署名がありません（Windows SmartScreen と macOS Gatekeeper が警告を出します）。
