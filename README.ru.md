# kikitori（聞き取り）

[繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [English](README.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português (Brasil)](README.pt-BR.md) | **Русский** | [Tiếng Việt](README.vi.md) | [ไทย](README.th.md) | [Bahasa Indonesia](README.id.md)

*Это перевод README.zh-TW.md на традиционном китайском; при расхождениях действует README.zh-TW.md. Перевод выполнен с помощью ИИ; исправления приветствуются через [issues](https://github.com/alianlbj23/kikitori/issues).*

kikitori слушает звук, который сейчас воспроизводит ваш компьютер (или микрофон), в реальном времени распознаёт речь, переводит её на выбранный язык и показывает двуязычные субтитры поверх экрана.
Распознавание речи (Whisper) и перевод (локальный Ollama) выполняются на вашем компьютере: звук и текст не отправляются ни в какие облачные сервисы.

Основной сценарий — **просмотр стримов японских VTuber** (с BGM, звуками игр и стримерским сленгом); рекомендации моделей и параметры подобраны по замерам этого проекта.
Любые другие сочетания из 20 языков тоже работают.

- Платформы: Windows 10/11 x64 (основная проверенная платформа), Linux x64, macOS Apple Silicon
- Лицензия: MIT (у моделей свои лицензии, см. «Лицензии»)
- Текущая версия: 0.2.0 ([что нового](docs/release-notes/v0.2.0.md))

## Возможности

| Возможность | Описание |
|---|---|
| Перевод видео | Захватывает звук, воспроизводимый системой (Windows WASAPI loopback / Linux PulseAudio monitor / macOS ScreenCaptureKit), и переводит язык речи на язык субтитров |
| Синхронный перевод | Захватывает микрофон: когда вы говорите на «Моём языке», речь переводится на язык собеседника, а речь собеседника — на ваш язык |
| Два прохода: сначала быстро, потом точно | Пока фраза ещё звучит, более быстрая модель сразу выдаёт «мгновенные субтитры»; когда фраза закончена, более точная модель пересчитывает «итоговые субтитры» и заменяет ими мгновенные |
| Стабильные мгновенные субтитры | Начало мгновенного субтитра, которое уже не изменится, показывается обычным цветом, а ещё меняющийся хвост — бледным; перевод больше не мигает вслед за хвостом |
| 20 языков в любых сочетаниях | Язык речи (можно выбрать «Определять автоматически») и язык субтитров выбираются из 20 языков, см. «Поддерживаемые языки» |
| 13 языков интерфейса | По умолчанию следует языку ОС; переключается на странице настроек |
| Только оригинал | Если выключить «Показывать перевод», виден только оригинал: Ollama не нужен, GPU не занят; переключается и во время работы |
| Фуригана | Чтения над кандзи японского оригинала (SudachiDict, около 69 MiB, скачивается только при первом включении) |
| Подбор моделей под оборудование | Определяет CPU, память, видеокарту NVIDIA и Ollama и автоматически выбирает сочетание моделей; недостающие модели скачиваются только при первом нажатии «Запустить» |
| Глоссарий | 53 встроенных термина японских стримов (赤スパ, 推し, メン限…) и легко путаемые китайско-японские слова для перевода с китайского на японский; можно добавлять свои записи, импорт/экспорт CSV |
| Экспорт расшифровки | SRT, VTT, TXT, CSV; можно включить автосохранение в конце каждого сеанса |
| Текстовый файл для OBS | Записывает текущие субтитры в текстовый файл для источника OBS «Текст (GDI+)» с опцией «Чтение из файла»; сетевые порты не открываются |
| Окно субтитров | Прозрачное, поверх всех окон, со сквозными кликами; настраиваются размер шрифта, фон, положение, число фраз, минимальное время показа фразы и задержка до затухания при простое |
| Строка состояния | Индикатор громкости, задержка (медиана от конца фразы до итогового субтитра); предупреждает, если распознавание не успевает или звука нет 15 секунд |
| Управление моделями | Скачивание, просмотр занятого места на диске и удаление моделей распознавания; скачивает модели перевода в Ollama за вас |
| Автообновление | При запуске проверяет GitHub Releases, скачивает обновление, проверяет подпись и устанавливает |

| Italiano | العربية | हिन्दी | Bahasa Indonesia | Tiếng Việt |

- Субтитры на традиционном китайском преобразуются через OpenCC `s2twp` в принятое на Тайване традиционное письмо и тайваньскую лексику (например, 视频 → 影片). Преобразование выполняется, только если в переводе есть упрощённые иероглифы, и «台灣» не заменяется на «臺灣».
- Если язык речи и язык субтитров совпадают, перевод не выполняется (между традиционным и упрощённым китайским только преобразуется письмо).
- Качество распознавания речи зависит от языка. Если доля ошибок модели на каком-либо языке выше 20% (например, тайский, арабский и хинди у large-v3-turbo, вьетнамский у large-v3), в пояснении к рекомендации указывается, что качество распознавания ниже; для тайского, арабского и хинди на видеокартах от 8 GB мгновенные субтитры тоже переключаются на large-v3.

Языки интерфейса (13): 繁體中文（台灣）, 简体中文, English, 日本語, 한국어, Español, Français, Deutsch, Português (Brasil), Русский, Tiếng Việt, ไทย, Bahasa Indonesia.
Арабский можно выбрать как язык речи или субтитров, но арабского интерфейса нет (интерфейс не поддерживает раскладку справа налево).

## Рекомендуемые сочетания (по оборудованию)

kikitori определяет оборудование и применяет сочетание автоматически; таблица лишь показывает, что вы получите. Основа — оценки этого проекта (`experiments/vtuber_eval/`, `experiments/translate_eval/`); правила и формулы описаны в [`docs/specs/hardware.md`](docs/specs/hardware.md).

| Ваш компьютер | Мгновенные субтитры | Итоговые субтитры | Перевод (Ollama) |
|---|---|---|---|
| NVIDIA от 16 GB | large-v3-turbo (float16) | large-v3 (float16) | qwen3.5:9b |
| NVIDIA 12 GB (например, RTX 5070) | large-v3-turbo (int8_float16) | large-v3 (int8_float16) | qwen3.5:9b |
| NVIDIA 8–11 GB | large-v3-turbo (small, если видеопамять ровно на нижней границе 8 GB) | large-v3 (точность вычислений по объёму видеопамяти) | qwen3.5:4b |
| NVIDIA 4–8 GB | base | large-v3-turbo | qwen3.5:4b |
| NVIDIA менее 4 GB | base | small | qwen3.5:4b |
| Без GPU NVIDIA, RAM ≥ 16 GB, от 5 ядер | base (CPU) | small (CPU) | qwen3.5:4b |
| Без GPU NVIDIA, меньше RAM или не более 4 ядер | tiny (CPU) | base (CPU) | qwen3.5:4b |
| Mac (Apple Silicon) | base (CPU) | small (CPU) | По объёму объединённой памяти (16 GB: qwen3.5:9b) |

- По замерам точности int8_float16 и float16 дают одинаковое качество распознавания (разница незначима), но int8_float16 занимает примерно вдвое меньше видеопамяти. Когда распознавание делит видеокарту с моделью перевода, kikitori отдаёт приоритет модели перевода, чтобы она могла быть на ступень больше.
- Объём загрузки моделей распознавания: large-v3-turbo 1.62 GB, large-v3 3.09 GB, small 487 MB, base 148 MB, tiny 78 MB. Модели перевода: qwen3.5:9b около 6.6 GB, qwen3.5:4b около 3.3 GB.
- Для GPU NVIDIA нужен cuBLAS 12 (около 570 MB). kikitori не включает его в установщик; он скачивается одним нажатием на странице «Модели» после принятия NVIDIA EULA. Без него используется CPU.
- Если сервер перевода находится на другом компьютере (удалённый), модель перевода не выбирается автоматически; выберите её сами на странице «Модели».
- Для перевода всегда рекомендуется прежде всего Qwen3.5 (Apache-2.0): 9B, если хватает видеопамяти, иначе 4B. При видеокарте менее 4 GB или без GPU NVIDIA тоже выбирается qwen3.5:4b; то, что не помещается, Ollama выполняет на CPU, и это медленнее (задержка перевода в этом случае ещё не измерялась).
- У Tencent HY-MT есть региональные ограничения: его могут рекомендовать, только если в настройках в разделе «Регионы лицензий моделей перевода» вы подтвердили, что не используете kikitori в ЕС, Великобритании или Южной Корее. Sakura (некоммерческая лицензия) никогда не рекомендуется, её можно выбрать только вручную.
- Скорость распознавания на macOS и Linux, а также скорость перевода на CPU ещё не измерялись (см. «Известные ограничения»).

## Начало работы

1. Скачайте установщик со страницы [GitHub Releases](https://github.com/alianlbj23/kikitori/releases) (подсказки по установке для каждой платформы есть на странице релиза: предупреждения SmartScreen/Gatekeeper из-за отсутствия подписи, fuse3 и шрифты в Linux).
2. Для перевода установите [Ollama](https://ollama.com/download) и оставьте его работать в фоне. Если kikitori его не найдёт, он предложит «Установить Ollama» или «Только оригинал».
3. Откройте kikitori. При первом запуске рекомендуемое для вашего оборудования сочетание применяется автоматически.
4. В настройках в разделе «Языки» выберите язык речи и язык субтитров. После выбора показываются только рекомендуемое сочетание и объём загрузки; **сразу ничего не скачивается**.
5. Выберите источник звука и нажмите «Запустить». Недостающие модели распознавания и перевода (в случае Ollama) сначала скачаются, после чего субтитры запустятся автоматически.

### Только оригинал

Переключатель «Показывать перевод» на панели инструментов страницы «Расшифровка» и в разделе «Субтитры» настроек (или сочетание клавиш Ctrl+Alt+J). Когда он выключен:

- движок вообще не подключается к серверу перевода, устанавливать Ollama не нужно, и GPU не занимается моделью перевода;
- окно субтитров показывает оригинал размером и цветом основных субтитров;
- переключение во время работы применяется сразу; уже показанные фразы потом не переводятся.

### Фуригана

Настройка «Показывать фуригану над японским оригиналом»: если язык речи японский, над кандзи оригинала показываются чтения хираганой (окуригана / 送り仮名 повторно не размечается). При первом включении скачивается SudachiDict core (Apache-2.0, около 69 MiB); на странице «Модели» можно посмотреть занятое место и удалить словарь. Влияет только на отображение, экспортируемые субтитры не меняются. Подробнее об устройстве: [`docs/specs/furigana.md`](docs/specs/furigana.md).

### Глоссарий

Раздел «Глоссарий» в настройках:

- **Встроенные термины стримов** («Использовать встроенные термины стримов», по умолчанию включено): применяются, когда оригинал на японском, а субтитры на традиционном/упрощённом китайском, английском или корейском; например, с английскими субтитрами スパチャ → Super Chat, メン限 → members-only, 切り抜き → clip. В промпт перевода попадают только термины, которые действительно встречаются в этой фразе (не более 8 на фразу).
- **Китайско-японские «ложные друзья»** (включаются вместе со встроенными терминами): когда оригинал на китайском, а субтитры на японском, модели подсказываются слова, которые пишутся в китайском и японском одинаково или похоже, но значат разное, например 便當 → 弁当, 節目 → 番組, 老婆 → 妻. Кроме того, при переводе с китайского на японский инструкции для модели пишутся на китайском, чтобы она реже читала китайский текст в японских значениях.
- **Свои записи**: оригинал, перевод и язык субтитров, к которому запись относится (или «Все языки»); до 500 записей, работают для любого языка речи; при одинаковом написании имеют приоритет над встроенными терминами. Сравнение не учитывает регистр и полную/половинную ширину символов.
- Импорт/экспорт CSV (UTF-8, разделитель — запятая, точка с запятой или Tab; файлы, сохранённые в Excel, тоже читаются). После нажатия «Сохранить глоссарий» изменения вступают в силу при следующем запуске субтитров.

### Экспорт расшифровки

«Экспорт» на странице «Расшифровка»: SRT, VTT, TXT, CSV; содержимое на выбор: «Оригинал и перевод», «Только оригинал», «Только перевод». Экспортируются только итоговые субтитры (мгновенные ещё меняются).
Файлы сохраняются в `Документы/kikitori/transcripts/YYYY-MM-DD_HHMMSS_<режим>.<расширение>`, тайм-коды отсчитываются от запуска субтитров.
В настройках можно включить «Автоматически сохранять в конце каждого сеанса (SRT и TXT)»; после нажатия «Остановить» kikitori ждёт итоговый субтитр последней фразы (не более 2 секунд) и затем сохраняет.

### Текстовый файл для OBS

Настройки, раздел «Расшифровки и OBS» → «Записывать субтитры в текстовый файл (для OBS)»: оригинал, перевод или оба.
kikitori перезаписывает `Документы/kikitori/obs/subtitle.txt` текущими фразами окна субтитров (UTF-8, атомарная запись, не чаще 10 раз в секунду);
в OBS добавьте источник «Текст (GDI+)», включите «Чтение из файла» и укажите этот файл. Когда субтитры заканчиваются, затухают при простое или очищаются, файл очищается.
Сетевые порты не открываются, поэтому варианта с источником OBS «Браузер» нет.

### Глобальные сочетания клавиш

| Windows / Linux | macOS | Действие |
|---|---|---|
| Ctrl+Alt+K | ⌘+Option+K | Переключить сквозные клики окна субтитров |
| Ctrl+Alt+J | ⌘+Option+J | Переключить «Показывать перевод» |
| Ctrl+Alt+U | ⌘+Option+U | Очистить окно субтитров (и текстовый файл OBS); расшифровка не затрагивается |

Сочетания, занятые другими программами, помечаются на странице «Расшифровка» как недоступные; на остальные сочетания это не влияет. В Linux с Wayland глобальные сочетания клавиш могут вообще не регистрироваться.

## Конфиденциальность и офлайн-работа

- Звук, результаты распознавания и переводы обрабатываются только на вашем компьютере. По умолчанию перевод отправляется в локальный Ollama (`http://localhost:11434/v1`); если вы укажете для сервиса перевода другой адрес, текст субтитров будет отправляться туда.
- В сеть kikitori выходит только для: загрузки моделей (модели распознавания с Hugging Face, модели перевода через Ollama, компоненты GPU с PyPI — всё это только когда вы нажимаете запуск или загрузку) и проверки обновлений при запуске (GitHub Releases). Когда все модели скачаны, сами субтитры работают полностью офлайн.
- API-ключ читается только из переменной окружения (в настройках хранится лишь имя переменной, по умолчанию `KIKITORI_TRANSLATE_API_KEY`) и не записывается ни в какие файлы.
- «Скопировать диагностику» на странице «О программе» копирует только в буфер обмена; ключи, учётные данные в URL и имена пользователей скрываются, от глоссария указывается только число записей.
- Движок и настольное приложение общаются только через стандартные ввод и вывод, без сетевых портов.

- Исправлено: модель оставалась в GPU, если устройство не удавалось открыть; каждый запуск субтитров занимал примерно на 17 MiB видеопамяти больше; память главного окна постоянно росла при долгой работе

## Известные ограничения

- **Полностью проверено только на Windows (RTX 5070)**. Реальный захват звука на macOS и Linux, а также скорость перевода на Apple Silicon и CPU не измерялись; Linux проверялся только в контейнере Docker.
- **Новые рекомендуемые сочетания измерены от начала до конца только на RTX 5070 (12 GB)**: при одновременной работе turbo + large-v3 (int8_float16) и qwen3.5:9b вся карта занята максимум на 10.8 GB, задержка мгновенных субтитров около 0.31 секунды, от конца фразы до итогового субтитра — около 0.92 секунды (медиана, см. [`tasks/acceptance-report-v0.2.0.md`](tasks/acceptance-report-v0.2.0.md)).
- **Материал для оценки точности распознавания — не VTuber**: использовались обычная разговорная речь с YouTube (YODAS), чтение вслух и телевизионная речь с подмешанной BGM; данных по песенным стримам, крикам и коллаборациям нескольких человек нет. Пение проходит через детектор речи и может давать странные субтитры.
- Для языков, кроме английского, есть только открытые бенчмарки и тесты на галлюцинации на неречевых звуках, проверок на реальной речи не было; список фраз-галлюцинаций не проверялся носителями языка.
- Некоторые завершающие фразы (например, «チャンネル登録よろしくお願いします») целиком отфильтровываются как галлюцинации Whisper, даже если стример действительно их произнёс.
- Для перевода нужно отдельно установить Ollama; на OpenAI-совместимых серверах, отличных от Ollama, модели нужно устанавливать самостоятельно.
- Нагрузочные тесты памяти при долгой работе проводились на Windows (движок стабилен в 20-минутном сеансе, главное окно за 22 минуты +0.7 MiB/мин); на macOS и Linux не тестировалось.
- Одновременно возможен только один сеанс субтитров; после отключения устройства автоматического переподключения нет.
- Не поддерживается: поиск слова по щелчку, захват звука только одного приложения, режим песенного стрима, разделение говорящих, источник OBS «Браузер» (причины см. в разделе «Пока не делаем» (先不做) документа [`docs/specs/competitive-features.md`](docs/specs/competitive-features.md), написанного на китайском, и в [`docs/adr/`](docs/adr/)).
- У установщиков нет платной подписи кода (Windows SmartScreen и macOS Gatekeeper показывают предупреждения).
